# Windows 任务栏适配真机验证

范围：正式应用中的任务栏适配（`src/BingLan.App/Taskbar/TaskbarAdapter.cs`）和“桌面模式”编排，对应 `DESKTOP-SHELL-AND-SURFACES.md` 第 6 节第 4、5 步。规则与持久化由 `tests/BingLan.SmokeTests` 覆盖。

## 实现要点

- **透明**：Windows 11 Build 26200 与 26300 使用自有 XAML 组件，只改变任务栏背景的透明度，保留原属性并在停止时恢复。其他 Windows 11 版本改用模糊并提示“此 Windows 版本暂用模糊代替透明”。Windows 10（Build 19041–21999）使用窗口材质 `ACCENT_ENABLE_TRANSPARENTGRADIENT`（渐变色 0），与模糊共用保活和检查点恢复（恢复时材质设回禁用），不加载 XAML 组件。远程会话、高对比度或检测到其他任务栏工具时保持默认；系统透明效果关闭时由宿主自动开启并在恢复时还原原值（用户开启期间手动关闭则让出）。结构、构建和恢复协议见 [任务栏 XAML 适配](TASKBAR-XAML.md)。
- **模糊**：保留系统窗口材质后端；实际效果随 Windows 版本变化，不将接口成功视为视觉成功。
- **自动隐藏**：通过文档化的 `SHAppBarMessage(ABM_SETSTATE)` 开启系统自动隐藏；原本已开启时不接管。用户自行关闭时尊重该选择。
- **恢复**：修改前记录恢复信息。透明背景在正常退出、宿主异常退出或心跳失效后由 Explorer 内组件恢复；自动隐藏和旧版窗口材质仍使用退出、下次启动和 `--restore-taskbar` 恢复。恢复未确认时保留检查点。

## 2026-10-03 透明效果实测

环境：Build 26200，浅色主题，Windows 透明效果开启，按用户安装的正式版本，TranslucentTB 已退出。在任务栏内距屏幕底边 12 px 处取样；x=300 处任务栏正上方的壁纸是深色岩石（`#6A767E`），x=600 处是水面。

| 任务栏状态 | x=300 | x=600 | 结论 |
| --- | --- | --- | --- |
| 系统默认 | `#DADADA` | `#DADADA` | 浅灰 |
| 冰蓝“透明”（`ACCENT_ENABLE_TRANSPARENTGRADIENT`，颜色 0） | `#D2F0F5` | `#D2F0F5` | 均匀浅蓝，两处颜色相同，不透出壁纸 |
| 同上，Flags=2 | `#E2E9EB` | `#D6ECF1` | 随壁纸略有变化，仍接近白色 |
| 冰蓝“模糊”（`ACCENT_ENABLE_BLURBEHIND`） | `#E0E7E9` | `#D5EBF0` | 同上 |
| `ACCENT_ENABLE_ACRYLICBLURBEHIND`、`ACCENT_ENABLE_HOSTBACKDROP` | `#DADADA`–`#DBDBDB` | `#DADADA` | 与系统默认相同 |
| TranslucentTB 运行 | `#C0B1AA` | `#627A7E` | 透出壁纸 |

结论：这台机器上，不注入 Explorer 的方式不能让任务栏透出壁纸。Windows 11 的任务栏背景由 Explorer 内的 XAML 层绘制，`SetWindowCompositionAttribute` 只改变它下方的窗口材质；TranslucentTB 通过加载到 Explorer 内的组件修改这一层。当前“透明”“模糊”两个模式只改变底色。

## 只在两角唤出（2026-10-04）

底边中间放一条 2 像素高、透明度 1/255 的置顶工具窗口，挡在自动隐藏的任务栏前面。实验：没有细条时鼠标到底边中间任务栏弹出（顶边 1438 → 1380），放上细条后不弹出。用模拟鼠标输入测试“两端照常弹出”时，连没有细条的对照组也时弹时不弹，模拟输入不足以验证，需以真实鼠标确认。

## 原有窗口材质后端的限制

- 恢复时透明、模糊一律回到 Windows 系统默认外观。Windows 没有读取任务栏当前材质的接口，冰蓝桌面只在检测不到其他任务栏工具时接管，按“接管前就是系统默认”处理；如果名单之外的工具事先改过任务栏外观，退出后不会还原成那个外观。
- 安装、更新和卸载时按安装路径强制结束冰蓝桌面，最后约 350 ms 内尚未落盘的改动可能丢失；任务栏与桌面图标的恢复记录不受影响。
- 从托盘或组件菜单“退出”的恢复路径与“切回系统默认”共用同一段代码，本轮没有单独在真机上点击退出验证。
- 系统界面换回材质到重新设置之间可能有一瞬间的闪烁；兜底补设间隔为 2 秒。
- 应用请求注意（任务栏按钮闪烁）时，Windows 会让自动隐藏的任务栏保持显示，此时任务栏会盖住 Dock 下沿。
- 注销或关机时会按正常退出恢复自动隐藏；下次登录启动后重新应用。
- 未覆盖：多显示器（副任务栏）、100%/150% 缩放、远程桌面、卸载程序调用。
- Windows 10 的自动隐藏、模糊、透明尚未经真机验证。待验证：三种样式的视觉效果；开始菜单、通知中心开合和窗口最大化后样式是否保持；Explorer 重启后重新应用；切回默认与正常退出后恢复；强制结束后下次启动按检查点恢复；多显示器时副任务栏同样生效。
