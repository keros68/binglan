# 开发说明

面向 Windows 11 的轻量桌面伴侣：用一套冰蓝设计语言统一桌面信息、应用 Dock、安全分组盒和原生任务栏外观。安装包最低允许 Windows 10 2004（Build 19041）：任务栏外观按 Build 22000 门控，设置窗口 Mica 按 Build 22621 门控，图标字体回退到 Segoe MDL2 Assets；Windows 10 尚未真机验证。

本文记录技术方案、当前实现、构建与测试。面向普通用户的说明见[使用说明](USER-GUIDE.md)。

四类能力使用各自适合的产品结构：时间/天气/性能采用低干扰信息层，待办采用 Reminders 风格内容卡，分组盒负责安全路径映射与整理，冰蓝 Dock 负责应用启动与窗口切换，原生任务栏适配只负责透明/模糊和智能隐藏。统一的是冰蓝材质、字体、颜色、间距、动效、逐卡拖动/锁定规则和 App 设置入口，不是同一种卡片底座。职责边界与实施顺序见 [桌面表面、冰蓝 Dock 与原生任务栏设计决策](DESKTOP-SHELL-AND-SURFACES.md)。

## 技术方案

- **.NET 10 LTS + WPF**：使用成熟的 Windows 桌面窗口、输入、拖放和 Shell 能力，避免为 MVP 引入自定义渲染引擎。整个程序使用 WPF 软件渲染，不在进程里创建显卡设备；卡片内容缓存为位图，拖动时只移动位图。在一台 1440p、NVIDIA 显卡的机器上实测：私有内存约 160 MB → 88 MB，空闲 CPU 约为单核的 1.5%。
- **开机启动顺序**：开机后 3 分钟内启动时，桌面卡片先显示；等资源管理器的桌面和任务栏就绪后再等 20 秒，才恢复或隐藏桌面图标、应用 Dock 和任务栏外观，避免和正在初始化的资源管理器争抢。各步骤的时间记录在本机 `startup.log`，不上传。
- **单实例生命周期**：正式模式和隔离交互测试模式分别使用当前 Windows 会话内的单实例门禁；重复启动会立即退出，不会重复创建组件、托盘或并发写入同一状态文件，原实例退出或异常终止后可再次启动。
- **高对比度回退**：Windows 对比度主题开启时，正式组件、设置中心和外观面板会立即改用不透明系统色；关闭后恢复用户原有的冰蓝材质与自定义颜色。
- **桌面组件窗口**：每个组件都是 WPF 逐像素透明的无边框工具窗口；正式路径禁用可能按矩形 HWND 绘制的 WCA 模糊，统一使用圆角 Clip 内的半透明冰蓝材质。普通应用窗口会自然覆盖组件，不修改 Explorer、任务栏或系统设置。“显示桌面”（Win+D）由两层机制保证组件保留：其一，Shell 若把组件窗口隐藏或最小化（不同 Windows 版本对工具窗口的处理不同），窗口会在下一条消息内用 `SW_SHOWNOACTIVATE` 自行恢复显示、回到原位，不抢前台焦点（状态读自原生窗口，因为 WPF 察觉不到其他进程对可见性的修改）；其二，Windows 11 的“显示桌面”还会把桌面表面（Progman）抬到普通窗口区上方、盖住垫底的组件——窗口状态完好但像素被壁纸盖住——`DesktopSurfaceWatcher` 通过 WinEvent 前台/最小化事件触发检查并从 Z 序读取“桌面已显示”状态（判定只看其他普通窗口是否全部最小化，不依赖组件自身位置，避免来回震荡；仅点击桌面而窗口未最小化时不会误判），期间组件被提升到置顶带（任务栏正下方、按卡片顺序堆叠、不激活、新出现的卡片自动跟随提升），普通窗口恢复后自动回落到普通窗口下方。托盘“隐藏桌面组件”和组件可见性设置走 `HideFromApp`，不会被恢复。
- **内容与设置分离**：普通桌面状态只显示标题、数据、待办、文件入口和直接内容动作；单击选中卡片时只临时显示一个统一设置入口。所有卡片及其显示、锁定、颜色、圆角、尺寸和内容配置集中在冰蓝桌面 App 的“桌面组件”页，以左侧组件列表和右侧详情呈现。
- **冰蓝材质个性化**：主体、文字、圆角、字号和信息密度按组件独立保存，并从统一设置中心调整。文字颜色提供白色、黑色快捷项和自定义值；不存在的本机字体会回退到可用字体。材质是共享设计令牌，但信息层、待办、分组盒和 Dock 不强制使用同一种容器骨架。
- **单一可调圆角**：关闭 DWM 非客户区边框与第二层系统圆角，使用唯一的 WPF `RectangleGeometry` 同时裁剪标题、主体和所有内容；不再使用会产生二值硬边的 HWND Region。待办与文件盒都可在设置中调节 `0–32 DIP`，默认 `15.5 DIP`。
- **逐卡拖动与锁定**：卡片默认可直接从标题或非交互空白区域拖动；复选框、文本输入、删除和新增等内容控件不会被当成拖动区域。每张卡片可在“桌面组件”页单独锁定，锁定后内容仍可操作；拖动卡片边缘或四角可调整大小，也可在对应组件详情中输入精确尺寸。双击待办、便签或分组盒的标题（或按 F2）可修改标题，Enter 确认，Esc 放弃。
- **原生任务栏边缘保护**：冰蓝桌面不写入 Windows 自动隐藏开关；检测到系统在某一显示器边缘启用自动隐藏时，桌面组件只为该边保留可唤出的窄边，不缩放卡片，也不限制没有任务栏的其他边。
- **普通便签**：支持多行纯文本、400 ms 去抖保存、正文的字体/字号/颜色/粗斜体/对齐（选中便签后点击标题栏的“Aa”展开），以及锁定位置后继续编辑；可从托盘或任一组件右键菜单新建。
- **低干扰桌面信息**：时间日期、问候语、天气、CPU/RAM/网络已经拆成四个独立表面，可分别显示、定位、缩放和设定外观，但共享同一份称呼、城市、天气与性能服务。时间、日期和问候的裸文字默认白色并带轻微对比度暗影，深浅壁纸下都可读。统一设置窗口支持手动搜索并选择天气城市：国内省、市、区县在内置离线城市库本地匹配（不联网、不发关键词，同名区县成对返回；数据来源与生成记录见 [CITY-DATA.md](CITY-DATA.md)），库内没有的境外地名才联网使用 OpenStreetMap Nominatim（只返回居民点，可搜到乡镇，候选显示上级行政区以区分同名地点，相邻请求至少间隔 1 秒，超时 15 秒）。天气请求只发送用户主动搜索的关键词及所选地点坐标，具备超时（15 秒）、指数退避、内存缓存和城市切换隔离；成功后每 15 分钟刷新，失败后按退避时间自动重试（开机时网络或代理尚未就绪也会自行恢复）。
- **卡片外观**：“外观”页可选浅色玻璃（冰蓝、奶茶、抹茶、北欧、玫瑰、薄荷六套配色）、深色玻璃或无底板，并调整玻璃浓度；文字颜色可跟随外观或固定为白色、深色，与外观分开设置；无底板时卡片只显示文字和图标，并自动加上柔和文字阴影。选择后应用到所有卡片，之后仍可单独调整；每张卡片的外观面板顶部有一排配色色块，点一下同时换背景、标题栏和文字颜色。
- **字体**：字体选择器最前面是内置的开源字体（得意黑、Jost 的极细/细/常规/中粗、Quicksand 的细/常规，均为 SIL OFL 1.1），其后是本机字体；内置字体从程序资源加载，不安装到 Windows。时间、问候、天气和性能卡片可在“桌面组件”页单独选择字体，默认沿用界面字体。每张卡片还可单独切换浅色玻璃、深色玻璃或无底板，不影响其他卡片。
- **四套桌面预设**：设置中心可切换“静谧信息层”“冰川工作台”“通透苹果桌面”和“居中时钟”（大号时钟居中，问候语在底部，性能、天气、待办在右上排成一列）；预设只改变卡片位置，天气城市、待办、文件映射和应用绑定保持不变；预览图由程序按预设位置和当前卡片颜色绘制，与应用后的效果一致。
- **组件列表与详情**：“桌面组件”页统一列出时间日期、问候语、天气、性能、待办、快捷入口、便签和分组盒，并可新建待办便签、普通便签和分组盒；时间、问候、天气、性能和待办可调整显示、锁定、字号缩放、文字色、玻璃颜色/不透明度、圆角、信息密度和宽高，便签和分组盒可调整锁定、主体与标题栏颜色、文字颜色、不透明度、圆角、宽高和标题字体，分组盒还可把内容在图标瓦片与紧凑列表之间切换（只换显示方式，映射与原文件不变）。设置修改后立即生效：文字和数值输入在停顿约 0.5 秒、按回车或离开输入框后生效，便签与分组盒的颜色值在按回车或离开输入框后生效；布局预设选好后点击“应用布局”。“通用”页底部提供“退出冰蓝桌面”。音频可视化保留为后续独立组件。“外观”页可从 Rainmeter 皮肤导入外观：只读取皮肤里的字体、文字色、底色、强调色和圆角，确认后应用到所有卡片，导入前自动备份。快捷入口是一排线条图标，默认是此电脑、桌面、文档、下载、图片、回收站；选中“快捷入口”后可增删、排序、换图标，并把位置改成任意文件夹、程序或文件（最多 12 个，不进入主题导出），开启清爽桌面时自动显示。分组盒标题栏可折叠成一条，再点一下按原高度展开。性能卡按三栏显示 CPU、RAM 和网络，CPU、RAM 下方有随数值伸缩的蓝色细条，下载速率用同一种蓝色。
- **冰蓝 Dock**：默认关闭，在设置中心“Dock”页开启。Dock 在所选显示器底部居中显示固定应用和正在运行的应用：点击未运行的应用会启动，点击后台应用会切换，点击当前应用会最小化；同一应用的多个窗口合并为一个图标，右键可选择窗口、启动新实例、关闭窗口、打开文件位置、固定/取消固定、不在 Dock 中显示此应用（用于自己不在任务栏显示、Dock 却无法识别的悬浮条和小工具；Dock 页“不在 Dock 中显示的应用”可恢复，固定该应用也会恢复显示），以及为固定应用更换图标或恢复默认图标（图片统一保存为 128×128 PNG，只记录生成的文件名），拖动固定图标可调整顺序。Dock 只固定用户选择的应用，Windows 任务栏上已固定的应用可在 Dock 页点击“导入任务栏应用”导入；把程序或快捷方式（包括分组盒里的软件图标）拖到 Dock 上即可固定，Dock 右侧正在运行的应用拖到固定段即固定在该位置；“添加应用…”打开开始菜单应用列表，可搜索并一次勾选多个；Dock 页可调整图标大小（32–64）和距底部高度（0–64 DIP，默认 28 DIP，即 Dock 底边与任务栏上沿的距离，两种显示方式下都生效，调大间距时预留条随之变高）；Dock 页还可选择动效（标准/减弱/关闭）；关闭“显示冰蓝 Dock”时其余 Dock 设置变灰并保留。外观默认跟随卡片外观（配色、深色玻璃或无底板），也可改为自定义，用配色色块或任意颜色加 0–100% 不透明度。固定的应用排在前面，其他正在运行的应用排在后面，中间有一条分隔线。应用闪烁请求注意时（如微信新消息），图标右上角出现橙色标记，打开或关闭该窗口后消失；智能隐藏的 Dock 会短暂露出。“任务栏”页可打开“有新消息时不弹出任务栏”，即关闭 Windows 的“任务栏应用闪烁”，关掉恢复默认。显示方式可选“始终显示并保留屏幕底部空间”或“智能隐藏”；全屏应用运行时 Dock 退到后方或保持隐藏；保留模式下可开启“最大化窗口时让出底部空间”（默认关闭）：前台窗口在 Dock 所在显示器最大化时，Dock 释放预留条并把该空间还给窗口（Windows 会把已最大化的窗口重新铺满新工作区），自身按智能隐藏规则隐藏，鼠标移到屏幕底边可临时唤出；前台不再是最大化窗口后自动恢复预留并回到原位。智能隐藏模式无需该开关（该模式在窗口最大化时本来就会隐藏）。Dock 隐藏时缩成一个可拖动的角落把手（`DockHandleWindow`）：默认在所在显示器右下角与 Dock 同带（距底为“距底部高度”设置值），底色为固定的浅蓝色（冰蓝强调色减淡、约 95% 不透明度，不随 Dock 表面配色变化），悬停时完整 Dock 在把手旁原地展开（把手在屏幕左半侧时向右展开，行宽沿用常规上限），指针移开后按智能隐藏的延迟从展开位直接收起（条带位置只在隐藏后恢复，避免可见的“跳回底部”闪烁），把手留在原地；把手可拖到工作区任意位置，坐标按显示器相对 DIP 持久保存（跨重启恢复）；拖动依赖窗口级鼠标捕获（捕获失败立即终止，指针在窗口外松开也能正确结束）。真全屏（铺满显示器且非最大化的无边框窗口）时把手与 Dock 一样隐藏，而最大化铺满（如任务栏自动隐藏时）不再压制唤出——只有这类“真全屏”才保持智能隐藏的全屏例外。Explorer 重启后自动恢复，退出或进程结束时释放保留的屏幕空间。Dock 不替代开始菜单、系统托盘和通知。
- **Windows 任务栏**：设置中心“任务栏”页可选保持系统默认、透明、模糊或自动隐藏，默认保持系统默认。透明模式在 Windows 11 Build 26200 上通过自有原生组件控制 Explorer 的任务栏背景，已验证能透出后方背景；未知版本保持系统默认。该模式切回默认、退出或宿主异常结束后恢复背景，失去心跳 5 秒后也会停止修改。模糊模式使用系统材质，效果随 Windows 版本变化；自动隐藏使用 Windows 自带设置。检测到 TranslucentTB 等任务栏工具时让出，开始菜单、托盘、通知和任务栏按钮保持不变。任务栏在底部自动隐藏时（包括在 Windows 设置里开启的自动隐藏），可打开“只在屏幕左下角或右下角唤出”：底边中间铺一条 2 像素高、几乎透明的置顶细条（两端各留 15%，至少 160 DIP），鼠标碰到中间不再弹出任务栏；全屏应用运行时细条撤下，不修改 Windows 设置。实现边界与真机记录见 [任务栏验证](TASKBAR-QA.md)。
- **顶端信息条**：贴住所选显示器顶边的满宽信息条（高度可调（默认 32 DIP，24–48 DIP）、直角、深色菜单栏材质（默认 #1E1F24 配白字与底部细线；深色表面用 WCA 亚克力对壁纸做真实模糊并以深色薄纱压暗（设置中可用“磨砂玻璃”开关关闭），亚克力不可用、用户选浅色自定义材质或跟随卡片外观时同样回退半透明纯色；可自定义颜色和不透明度）），默认关闭，在设置中心“顶端信息条”页开启。它只承载冰蓝自有的只读数据：时钟与日期（12/24 小时制沿用时间卡设置）、待办概要（勾选图标旁显示未完成计数）、天气（城市、温度、现象；悬停展示高低温、湿度、更新时间与失败状态）、性能（CPU/内存/上下行速率）、电量、音量（只读）、网络，状态模块用任务栏同款 Segoe Fluent 图标显示（电池按电量档位与充电变化、Wi-Fi 连接状态、音量档位）,输入法（任务栏式中/英圆角徽标加输入法名：徽标显示“中”/“繁”或其英文模式的“英”、其他布局显示语言码，旁边常显当前输入处理器名（TSF，如“微信输入法”，纯 TSF 输入法在 imm32 注册表里查不到名字，普通键盘布局无此行）；悬停展示完整布局名，随前台窗口与输入法自身中英切换即时变化，打字高峰读不到模式时沿用上帧徽标）和消息提示（哪个应用在闪烁请求注意，最多显示 3 个，点击聚焦该应用；不提供角标数，不读取系统通知）。每个模块独立开关、默认全开；点击待办概要弹出待办清单浮层：条目点击即切换完成状态（与桌面待办卡共用同一状态对象，双向联动），点别处或再点收起；消息提示点击聚焦该应用；性能点击启动任务管理器并由后台 UIA 停留到“性能”页；电量/网络/音量点击程序化调用任务栏托盘图标、唤起与托盘一致的快速设置弹层（不用 Win+A——新版本 build 上它打开的是整个设置应用），时钟点击弹出日历信息栏（大号时间、今天日期、周一开头的只读月历、可前后翻月；系统的日历与快速设置面板在 Windows 11 26200 内嵌于任务栏渲染、无独立窗口无法重定位，故顶栏自建只读月历而不做系统面板搬运），输入法与天气同为纯展示元素（点击无动作）。显示方式可选“始终显示并预留屏幕顶部空间”（默认，预留高度为条高减 1 像素，最大化窗口顶边贴入信息条最后一行下方）或“智能隐藏”（鼠标贴顶边唤出、延迟收回）；顶边被系统任务栏占用（Windows 10 可把任务栏移到顶部）时自动按智能隐藏处理；真全屏应用运行时退避。系统事实读取全部只读且在后台线程完成（电量 `GetSystemPowerStatus`、音量 WASAPI COM、网络 `NetworkInterface` 与 `NetworkChange` 事件、输入法 `GetKeyboardLayout`、imm32 转换模式、TSF 输入处理器名与注册表布局名——徽标与模式经 150 毫秒前台节拍即时刷新，IME 询问带超时防挂起，TSF 名只在布局句柄变化时于 UI 线程重读），时钟与性能沿共享采样节拍。退出、崩溃或强杀后释放预留空间，Explorer 重启后重放；预留矩形未变化时不重发 `ABM_SETPOS`（每次重发都会广播系统工作区变化，实测会扰动微信 Alt+A 等截图工具的遮罩落屏）；“苹果式”桌面模式把它编排为开启并关闭时间/天气/性能三张桌面信息卡。设计依据与边界见 [顶端信息条设计](DESKTOP-TOPBAR-DESIGN.md)，真机记录见 [顶端信息条验证](TOPBAR-QA.md)。
- **主题包**：“外观”页可导出和导入 `.binglan-theme` 主题包，包含清单（主题 ID、名称、作者、主题版本、最低应用版本）、组件颜色、材质、圆角、字号、显示开关、按工作区比例保存的布局、整体风格（文字阴影、吸附间距、Dock 动效、任务栏透明或模糊）、Dock 应用槽位（如浏览器、聊天、音乐）及其自定义图标（每个 ≤256 KB PNG），和一张按布局绘制的示意预览图（非截图，≤1 MB；未能生成时导出结果会说明）。导出前先填写主题名称并查看将包含/排除的内容；导入前先看预览图、主题名称和将改变的内容再确认。主题包不含称呼、天气城市、待办、便签、文件映射、本机路径、壁纸和字体；导入时拒绝超过 5 MB、含路径穿越或程序/脚本文件的包，先备份当前设置，再把各应用槽位对应到本机已安装的同类应用，找不到的可在绑定向导中逐个选择本机应用或跳过，也可稍后在 Dock 页手动添加。
- **桌面模式**：“布局”页提供“Windows 原生”“冰蓝混合”“苹果式”三种模式，一次设置 Dock 与任务栏；两项仍可在各自页面单独调整。
- **整体风格**：“外观”页可设置文字阴影（无/柔和/明显，作用于卡片内的文字和图标）和吸附间距（拖动吸附时保留的距离，8/16/24 DIP），“Dock”页可设置 Dock 动效（标准/减弱/关闭；系统关闭动画时始终不动），导出主题时一并保存。
- **清爽桌面**：“布局”页可开启“隐藏 Windows 桌面图标”，默认关闭。开启前在分组盒中补齐此电脑、回收站、下载和桌面入口，只通过 Windows 文档化的 Shell 接口隐藏图标，不移动文件、不改图标位置、不重启 Explorer。开启前记录原状态；关闭、退出、下次启动（异常退出后）或运行 `BingLan.exe --restore-taskbar` 时恢复图标；在桌面右键菜单中重新显示图标时，清爽桌面自动关闭。
- **首次引导**：新安装首次启动时依次选择布局（或导入主题包）与冰蓝 Dock 所在显示器（列出分辨率和缩放）、称呼与天气城市、固定到 Dock 的常用应用和作为“下载”入口的文件夹、桌面模式；最后一步可勾选“进入桌面后打开设置中心”，也可随时跳过；升级用户不会看到引导。
- **拖动吸附**：卡片自己跟随指针移动，不受 Windows“拖动时显示窗口内容”设置影响。靠近工作区边缘或 64 DIP 内的其他卡片时自动对齐并保持所设吸附间距（默认 16 DIP），同时显示参考线；按住 Alt 拖动可暂时关闭吸附。卡片显示后和切换到其他窗口后位于普通窗口下方。
- **显示器变化恢复**：每张卡片按显示器排列（各显示器的位置、分辨率和缩放）分别记住位置，最多记 6 种排列；切换到见过的排列（如笔记本接回外接显示器）时卡片回到该排列下的位置，切换过程中被系统或恢复逻辑挪动的位置不会覆盖已记住的位置。首次出现的排列中落到屏幕外的卡片会移回可见区域；“桌面组件”页可把单张卡片恢复到默认位置。托盘菜单可一键隐藏或重新显示全部桌面组件。
- **检查更新**：设置中心“通用”页显示当前版本，默认每天自动检查一次 GitHub Releases 的最新版本（开机桌面就绪后开始，失败的检查一小时后再试），也可手动检查或关闭自动检查；请求只带程序名和版本号。发现新版本时托盘提示并在托盘菜单出现入口，页面显示更新说明；只有点击“下载并安装”才下载安装包，大小和 SHA-256 与 GitHub 公布值一致后以 `/SILENT /UPDATE=1` 启动安装程序并退出，安装程序恢复任务栏后替换文件并重新打开冰蓝桌面。没有可校验安装包的版本只提供发布页链接。交互测试模式不自动检查。
- **开机启动、备份与恢复**：“通用”页可开关登录 Windows 时启动（当前用户的单个启动项，不需要管理员权限），列出本机数据位置和联网范围，并可立即备份、查看备份（列出时间、布局、卡片数和 Dock 应用数）并从备份恢复，恢复前先另存当前状态，随后自动重启应用。
- **本地持久化**：状态写入 `%LOCALAPPDATA%\BingLanWidgets\widgets.json`，采用临时文件替换，并保留上一版本 `.bak`；Schema v28 保存桌面布局预设、独立信息表面位置（含每种显示器排列下的位置）、组件目录、桌面信息设置、普通便签内容与排版、每个组件的圆角、材质外观、卡片文字颜色、标题字体、桌面分类身份、分组盒图标/列表视图、分组盒自动刷新开关、Dock 设置（开关、显示器、显示方式、固定应用、不在 Dock 中显示的应用、距底部高度、最大化让出开关、隐藏把手位置）、任务栏模式、更新检查设置、首次引导完成状态、清爽桌面开关、整体风格和顶端信息条设置（开关、显示方式、显示器、九模块开关、磨砂玻璃、外观与高度），并迁移旧状态而不改变个人内容；仍为旧默认色的时间文字迁移为白色，自定义颜色保持不变。

## 运行

构建需要 .NET 10 SDK、PowerShell 7、Visual Studio 2022 C++ x64 构建工具和 Windows SDK。原生任务栏组件随构建生成，安装用户无需安装这些工具。

```powershell
dotnet run --project .\src\BingLan.App\BingLan.App.csproj
```

首次运行会显示首次引导、桌面信息、一个待办便签和一个桌面分组盒，并在通知区域显示托盘图标。双击托盘图标会打开冰蓝桌面设置，窗口已最小化时会恢复到前台；重复启动不会创建第二套窗口或托盘。

从托盘或组件右键菜单选择“在冰蓝桌面中设置…”，也可单击卡片（或用 Tab 键把焦点移入卡片）后点击出现的设置按钮；同一个设置窗口会打开“桌面组件”页并直接选中当前卡片。左侧切换组件，右侧修改该卡片的显示、锁定、外观、尺寸和专属内容设置。只有主动搜索天气城市时才发送输入的关键词；不会使用 IP、GPS、Wi-Fi 或设备位置。

- 分组盒底部“自动整理”会把当前用户桌面和公共桌面的直接子项放进各分组盒：在“桌面组件”页选中某个分组盒，可勾选它收纳的类型（文件夹、软件与快捷方式、文档、图片、视频、音乐、压缩包）或填写其他扩展名；没有盒子收纳的项目归入“软件与快捷入口”“桌面文件夹”“桌面文件”三个盒子。重复执行只补新增映射，并清除原文件已被删除的“已失效”映射（所在磁盘未连接或网络共享离线时保留）；“布局”页的“分组盒自动刷新”开关（默认关闭）开启后，分组盒监听映射所在目录与桌面目录：原文件被删除后确认已删除的映射自动移除，桌面上新出现的项目自动收纳进已有分组盒（不新建分类盒；下载中的临时文件按扩展名跳过，改名完成后才入盒）；不会移动、隐藏、重命名或删除桌面原文件。
- 未锁定卡片可直接拖动标题或非交互空白区域；要避免误拖时，在“桌面组件”页选中该卡片并开启“锁定卡片位置”。
- 卡片宽高在对应组件详情中输入；待办文字始终可直接编辑，Enter 提交，Esc 放弃本次修改；空白行显示“输入待办…”提示，底部统计只计算写了内容的待办；“清理已完成”删除已完成项，“隐藏已完成/显示已完成”切换是否显示它们。
- 每条待办右侧的“×”删除该条；右键可上移、下移或删除。
- 文件、文件夹、快捷方式或 URL 拖进桌面分组盒只记录路径；双击打开，右键可调整手动顺序、修改显示名称（不重命名原文件）、转移到其他分组盒或移除映射；原路径不存在时会标记为“已失效”，确认原文件已删除（所在磁盘可访问）的映射会自动清除，因磁盘未连接或网络共享离线而失效的映射保留，右键可重新定位到新路径或移除。
- 点击分组盒标题栏的“+”会打开添加菜单，可选择文件、文件夹，一次导入当前用户桌面与公共桌面的第一层项目，或添加此电脑、回收站、下载、桌面等系统入口；底部常驻“自动整理”按钮会按软件入口、文件夹和文件生成或补充分组盒。操作区会显示新增数量或没有新项目的结果；导入、整理与排序都不会移动、重命名或删除原文件。
- 组件右键菜单只保留进入冰蓝桌面设置、删除组件和退出，不再复制一套桌面内设置。
