# 开发说明

面向 Windows 11 的轻量桌面伴侣：用一套冰蓝设计语言统一桌面信息、应用 Dock、安全分组盒和原生任务栏外观。安装包最低允许 Windows 10 2004（Build 19041）：任务栏外观按 Build 22000 门控，设置窗口 Mica 按 Build 22621 门控，图标字体回退到 Segoe MDL2 Assets；Windows 10 尚未真机验证。

本文记录技术方案、当前实现、构建与测试。面向普通用户的说明见[使用说明](USER-GUIDE.md)。

今日列表是周历当天格的投影：`BelongsToTodayList` 仅接受 `Date == DateTime.Today`，列表新增立即写入当天日期，顶栏计数与清理范围沿用同一口径。旧无日期任务在 `LocalStateStore.Load` 时按 `CreatedDate`、`CompletedDate`、迁移当天的顺序回填日期并立即保存，保留原任务、完成状态和时间戳。`TodoService.NormalizeTodayCompletionOrder` 在恢复、切回列表、今日新增和跨天时把当天未完成项排在已完成项前，其他日期任务仍留原日历日期；WPF 以 `ObservableCollection` 的增删与 `Move` 同步已渲染的列表和周历格。午夜计时器及窗口重新激活会刷新列表、周历和摘要。SchemaVersion 保持 33。

四类能力使用各自适合的产品结构：时间/天气/性能采用低干扰信息层，待办采用 Reminders 风格内容卡，分组盒负责安全路径映射与整理，冰蓝 Dock 负责应用启动、窗口切换和调用 Windows 原生开始菜单，原生任务栏适配只负责透明/模糊和智能隐藏。统一的是冰蓝材质、字体、颜色、间距、动效、逐卡拖动/锁定规则和 App 设置入口，不是同一种卡片底座。职责边界与实施顺序见 [桌面表面、冰蓝 Dock 与原生任务栏设计决策](DESKTOP-SHELL-AND-SURFACES.md)。

## 技术方案

- **.NET 10 LTS + WPF**：WPF 继续使用软件渲染；Windows 11 上 Dock 和隐藏把手的实时毛玻璃由系统 Windows Composition 合成层绘制。玻璃使用独立的无重定向位图窗口，跟随内容窗口的位置、尺寸、显隐和层级；形变只改变合成几何，不逐帧缩放原生窗口。高对比度、透明效果关闭、Windows 10 或初始化失败时恢复原半透明背景。新增 Windows SDK .NET 投影随程序分发，成本见 [安装包](INSTALLER.md)。
- **开机启动顺序**：开机后 3 分钟内启动时，桌面卡片先显示；等资源管理器的桌面和任务栏就绪后再等 20 秒，才恢复或隐藏桌面图标、应用 Dock 和任务栏外观，避免和正在初始化的资源管理器争抢。各步骤的时间记录在本机 `startup.log`，不上传。
- **单实例生命周期**：正式模式和隔离交互测试模式分别使用当前 Windows 会话内的单实例门禁；重复启动会立即退出，不会重复创建组件、托盘或并发写入同一状态文件，原实例退出或异常终止后可再次启动。
- **高对比度回退**：Windows 对比度主题开启时，正式组件、设置中心和外观面板会立即改用不透明系统色；关闭后恢复用户原有的冰蓝材质与自定义颜色。
- **桌面组件窗口**：每个组件都是 WPF 逐像素透明的无边框工具窗口；卡片继续使用圆角 Clip 内的半透明冰蓝材质；Dock 和把手使用原生合成毛玻璃与几何圆角裁剪，不使用 WCA。普通应用窗口会自然覆盖组件，不修改 Explorer、任务栏或系统设置。“显示桌面”（Win+D）由两层机制保证组件保留：其一，Shell 若把组件窗口隐藏或最小化（不同 Windows 版本对工具窗口的处理不同），窗口会在下一条消息内用 `SW_SHOWNOACTIVATE` 自行恢复显示、回到原位，不抢前台焦点（状态读自原生窗口，因为 WPF 察觉不到其他进程对可见性的修改）；其二，Windows 11 的“显示桌面”还会把桌面表面（Progman）抬到普通窗口区上方、盖住垫底的组件——窗口状态完好但像素被壁纸盖住——`DesktopSurfaceWatcher` 通过 WinEvent 前台/最小化事件触发检查并从 Z 序读取“桌面已显示”状态（判定只看其他普通窗口是否全部最小化，不依赖组件自身位置，避免来回震荡；仅点击桌面而窗口未最小化时不会误判），期间组件被提升到置顶带（任务栏正下方、按卡片顺序堆叠、不激活、新出现的卡片自动跟随提升；期间点击、拖动或收起组件引发的失活回落不会把组件压回桌面表面之下），普通窗口恢复后自动回落到普通窗口下方。托盘“隐藏桌面组件”和组件可见性设置走 `HideFromApp`，不会被恢复。
- **内容与设置分离**：普通桌面状态只显示标题、数据、待办、文件入口和直接内容动作；单击选中卡片时只临时显示一个统一设置入口。所有卡片及其显示、锁定、颜色、圆角、尺寸和内容配置集中在冰蓝桌面 App 的“桌面组件”页，以左侧组件列表和右侧详情呈现。
- **冰蓝材质个性化**：主体、文字、圆角、字号和信息密度按组件独立保存，并从统一设置中心调整。文字颜色提供白色、黑色快捷项和自定义值；不存在的本机字体会回退到可用字体。材质是共享设计令牌，但信息层、待办、分组盒和 Dock 不强制使用同一种容器骨架。
- **单一可调圆角**：关闭 DWM 非客户区边框与第二层系统圆角，使用唯一的 WPF `RectangleGeometry` 同时裁剪标题、主体和所有内容；不再使用会产生二值硬边的 HWND Region。待办与文件盒都可在设置中调节 `0–32 DIP`，默认 `15.5 DIP`。
- **逐卡拖动与锁定**：卡片默认可直接从标题或非交互空白区域拖动；复选框、文本输入、删除和新增等内容控件不会被当成拖动区域。每张卡片可在“桌面组件”页单独锁定，锁定后内容仍可操作；拖动卡片边缘或四角可调整大小，也可在对应组件详情中输入精确尺寸。双击待办、便签或分组盒的标题（或按 F2）可修改标题，Enter 确认，Esc 放弃。
- **原生任务栏边缘保护**：冰蓝桌面不写入 Windows 自动隐藏开关；检测到系统在某一显示器边缘启用自动隐藏时，桌面组件只为该边保留可唤出的窄边，不缩放卡片，也不限制没有任务栏的其他边。底边仍可唤出原生任务栏；用户选择只在左右角唤出后，才保护底边中间区域。
- **普通便签**：支持多行纯文本、400 ms 去抖保存、正文的字体/字号/颜色/粗斜体/对齐（选中便签后点击标题栏的“Aa”展开），以及锁定位置后继续编辑；可从托盘或任一组件右键菜单新建。
- **低干扰桌面信息**：时间日期、问候语、天气、CPU/RAM/网络已经拆成四个独立表面，可分别显示、定位、缩放和设定外观，但共享同一份称呼、城市、天气与性能服务。时间、日期和问候的裸文字默认白色并带轻微对比度暗影，深浅壁纸下都可读。统一设置窗口支持手动搜索并选择天气城市：国内省、市、区县在内置离线城市库本地匹配（不联网、不发关键词，同名区县成对返回；数据来源与生成记录见 [CITY-DATA.md](CITY-DATA.md)），库内没有的境外地名才联网使用 OpenStreetMap Nominatim（只返回居民点，可搜到乡镇，候选显示上级行政区以区分同名地点，相邻请求至少间隔 1 秒，超时 15 秒）。天气请求只发送用户主动搜索的关键词及所选地点坐标，具备超时（15 秒）、指数退避、内存缓存和城市切换隔离；成功后每 15 分钟刷新，失败后按退避时间自动重试（开机时网络或代理尚未就绪也会自行恢复）。
- **卡片外观**：“外观”页可选浅色玻璃（冰蓝、奶茶、抹茶、北欧、玫瑰、薄荷六套配色）、深色玻璃或无底板，并调整玻璃浓度；文字颜色可跟随外观或固定为白色、深色或自定义。快捷控件即时应用到所有卡片，之后仍可单独调整；每张卡片的外观面板顶部有一排配色色块，点一下同时换背景、标题栏和文字颜色。无底板时卡片只显示文字和图标，并沿用柔和文字阴影规则。
- **外观试选**：“试选外观…”在独立草稿中调整材质、六套配色、浓度和文字色，可切换原外观示例及浅深背景。示例使用固定内容和现有配色规则，不启动采样或读取个人内容；取消、Esc、关闭窗口均丢弃草稿，未修改时应用不写回。点击“应用”只提交五项卡片外观字段，再统一应用到卡片，保留个人内容、其他样式及 Dock 独立外观。
- **字体**：字体选择器最前面是内置的开源字体（得意黑、Jost 的极细/细/常规/中粗、Quicksand 的细/常规，均为 SIL OFL 1.1），其后是本机字体；内置字体从程序资源加载，不安装到 Windows。时间、问候、天气和性能卡片可在“桌面组件”页单独选择字体，默认沿用界面字体。每张卡片还可单独切换浅色玻璃、深色玻璃或无底板，不影响其他卡片。
- **四套桌面预设**：设置中心可切换“静谧信息层”“冰川工作台”“通透苹果桌面”和“居中时钟”（大号时钟居中，问候语在底部，性能、天气、待办在右上排成一列）；预设只改变卡片位置，天气城市、待办、文件映射和应用绑定保持不变；竖屏工作区采用居中的纵向构图；720×1280、864×1536、1080×1920 DIP 的五卡预设保持边界、最小尺寸和间距，极小工作区以可见性优先。预览与应用共用位置规则，缩略图保持工作区比例，外观和工作区变化后重新绘制；不改变已保存的手动位置，直到用户应用预设。
- **组件列表与详情**：“桌面组件”页统一列出时间日期、问候语、天气、性能、待办、快捷入口、便签和分组盒，并可新建待办便签、普通便签和分组盒；时间、问候、天气、性能和待办可调整显示、锁定、字号缩放、文字色、玻璃颜色/不透明度、圆角、信息密度和宽高，便签和分组盒可调整锁定、主体与标题栏颜色、文字颜色、不透明度、圆角、宽高和标题字体，分组盒还可把内容在图标瓦片与紧凑列表之间切换（只换显示方式，映射与原文件不变）。设置修改后立即生效：文字和数值输入在停顿约 0.5 秒、按回车或离开输入框后生效，便签与分组盒的颜色值在按回车或离开输入框后生效；布局预设选好后点击“应用布局”。“通用”页底部提供“退出冰蓝桌面”。音频可视化保留为后续独立组件。“外观”页可从 Rainmeter 皮肤导入外观：只读取皮肤里的字体、文字色、底色、强调色和圆角，确认后应用到所有卡片，导入前自动备份。快捷入口是一排线条图标，默认是此电脑、桌面、文档、下载、图片、回收站；选中“快捷入口”后可增删、排序、换图标，并把位置改成任意文件夹、程序或文件（最多 12 个，不进入主题导出），开启清爽桌面时自动显示。分组盒设置里提供“桌面上的原文件”提示，说明收纳不移动原文件，并可一键跳转到“外观”页开启“清爽桌面”。分组盒标题栏可折叠成一条，再点一下按原高度展开。性能卡按三栏显示 CPU、RAM 和网络，CPU、RAM 下方有随数值伸缩的蓝色细条，下载速率用同一种蓝色。
- **冰蓝 Dock**：默认关闭，在设置中心“Dock”页开启。Dock 在所选显示器底部居中显示固定应用和正在运行的应用：左端默认显示可关闭的 Windows 开始菜单入口，单击打开原生开始菜单，右键或菜单键、Shift+F10 打开原生 Win+X 快捷菜单，不参与应用排序、分组或运行状态。原生开始菜单、任务栏菜单和快速设置处于前台时，Dock 暂时收起，关闭后恢复原显示规则。点击未运行的应用会启动，点击后台应用会切换，点击当前应用会最小化；关闭窗口后驻留托盘的微信，点击时发送微信自己的“显示/隐藏窗口”快捷键（默认 Ctrl+Alt+W）唤回已登录的主窗口：仅在微信运行、没有可见窗口且该组合键已被注册时发送，1.5 秒内主窗口未出现（快捷键被改或关闭）则回退为启动程序，唤回期间重复点击不再发送快捷键，窗口已出现而 Dock 尚未刷新时直接切换；其他驻留托盘的应用点击启动，由应用自身的单实例机制唤回主窗口——应用隐藏的窗口不从外部强制显示（微信 4.x 实测强拉只会得到空白或无响应窗口）；同一应用的多个窗口合并为一个图标，右键可选择窗口、启动新实例、关闭窗口、打开文件位置、固定/取消固定、不在 Dock 中显示此应用（用于自己不在任务栏显示、Dock 却无法识别的悬浮条和小工具；Dock 页“不在 Dock 中显示的应用”可恢复，固定该应用也会恢复显示），以及为固定应用更换图标或恢复默认图标（图片统一保存为 128×128 PNG，只记录生成的文件名），拖动固定图标可调整顺序。Dock 只固定用户选择的应用，Windows 任务栏上已固定的应用可在 Dock 页点击“导入任务栏应用”导入；把程序或快捷方式（包括分组盒里的软件图标）拖到 Dock 上即可固定，Dock 右侧正在运行的应用拖到固定段即固定在该位置；“添加应用…”打开开始菜单应用列表，可搜索并一次勾选多个；固定时记下快捷方式的启动参数和工作目录，启动未运行的应用时原样带上（快捷方式未填工作目录时按程序所在文件夹启动，该文件夹已不存在时回退程序所在文件夹），依赖参数或工作目录的程序（如 AutoCAD、游戏启动器、部分国产软件）也能正常打开，升级前已固定的应用不含参数，重新固定后生效；Dock 页可调整图标大小（32–64）和距底部高度（0–64 DIP，默认 28 DIP，即 Dock 底边与任务栏上沿的距离，两种显示方式下都生效，调大间距时预留条随之变高）；Dock 页还可选择动效（标准/减弱/关闭）；关闭“显示冰蓝 Dock”时其余 Dock 设置变灰并保留。外观默认跟随卡片外观（配色、深色玻璃或无底板），也可改为自定义：配色色块或任意颜色加 5–96% 玻璃浓度（与整体风格的玻璃浓度同范围同语言，默认 84% 以便与跟随模式观感衔接）。固定的应用排在前面，其他正在运行的应用排在后面，中间有一条分隔线。应用闪烁请求注意时（如微信新消息），图标右上角出现橙色标记，打开或关闭该窗口后消失；智能隐藏的 Dock 会短暂露出。“任务栏”页可打开“有新消息时不弹出任务栏”，即关闭 Windows 的“任务栏应用闪烁”，关掉恢复默认。显示方式可选“始终显示并保留屏幕底部空间”或“智能隐藏”；全屏应用运行时 Dock 退到后方或保持隐藏；保留模式下可开启“最大化窗口时让出底部空间”（默认关闭）：前台窗口在 Dock 所在显示器最大化时，Dock 释放预留条并把该空间还给窗口（Windows 会把已最大化的窗口重新铺满新工作区），自身立即收进把手（经 SetWinEventHook 监听 EVENT_OBJECT_STATECHANGE，点最大化的当拍即评估：预留释放、窗口下探与收拢动画同时开始；150ms 轮询与状态机的立即收起规则兜底，指针在 Dock 上或交互中仍保持显示），鼠标移到屏幕底边可临时唤出；前台不再是最大化窗口后自动恢复预留并回到原位。智能隐藏模式无需该开关（该模式在窗口最大化时本来就会隐藏，同样立即收起）。Dock 隐藏时缩成一个可拖动的角落把手（`DockHandleWindow`）：默认在所在显示器右下角与 Dock 同带（距底为“距底部高度”设置值），底色为固定的浅蓝色（冰蓝强调色减淡、约 95% 不透明度，不随 Dock 表面配色变化），悬停时完整 Dock 在把手旁原地展开（把手在屏幕左半侧时向右展开，行宽沿用常规上限），指针移开后按智能隐藏的延迟从展开位直接收起（条带位置只在隐藏后恢复，避免可见的“跳回底部”闪烁），把手留在原地；悬停展开与收起均为形变动画：整行从把手一端生长或向把手收拢（收起发生在条带位置时窗口临时扩为条带与把手的行程包围盒，整行一路被“吸”向把手，落定后把手图标轻弹一下；形变只缩放窗口内容，不逐帧改窗口尺寸），底边唤出或遮挡消失后的重现是原地浮出（淡入并自底缘轻微放大），展开状态跳回条带保持瞬跳；动效遵守 Dock 动效档位（减弱档缩短时长且只缩不位移，关闭档与系统“显示动画”关闭时瞬切），动画进行中被指针返回、拖动把手或真全屏打断时从当前形态续接反向或立即落终态（`DockMorphMotion` 定规格，`DockMorphAnimator` 驱动）；把手可拖到工作区任意位置，坐标按显示器相对 DIP 持久保存（跨重启恢复）；拖动依赖窗口级鼠标捕获（捕获失败立即终止，指针在窗口外松开也能正确结束）。真全屏（铺满显示器且非最大化的无边框窗口）时把手与 Dock 一样隐藏，而最大化铺满（如任务栏自动隐藏时）不再压制唤出——只有这类“真全屏”才保持智能隐藏的全屏例外。Explorer 重启后自动恢复，退出或进程结束时释放保留的屏幕空间。保留屏幕空间时，Dock 只在预留条实际变化时向系统重新提交位置；与其他贴边工具栏（如文件管理器停靠在屏幕边缘的工具栏）之间的位置通知在 2 秒内超过 6 次时，改为每秒至多响应一次，避免两边互相触发、反复重排整个桌面（`AppBarPositionGuard`）。窗口事件只处理顶层窗口，窗口内控件的状态变化不触发 Dock 重新评估，处理前的连续事件合并为一次。Dock 不替代开始菜单、系统托盘和通知。

## 运行

构建需要 .NET 10 SDK、PowerShell 7、Visual Studio 2022 C++ x64 构建工具和 Windows SDK。原生任务栏组件随构建生成，安装用户无需安装这些工具。

```powershell
dotnet run --project .\src\BingLan.App\BingLan.App.csproj
```

首次运行会显示首次引导、桌面信息、一个待办便签和一个桌面分组盒，并在通知区域显示托盘图标。双击托盘图标会打开冰蓝桌面设置，窗口已最小化时会恢复到前台；重复启动不会创建第二套窗口或托盘。

从托盘或组件右键菜单选择“在冰蓝桌面中设置…”，也可单击卡片（或用 Tab 键把焦点移入卡片）后点击出现的设置按钮；同一个设置窗口会打开“桌面组件”页并直接选中当前卡片。左侧切换组件，右侧修改该卡片的显示、锁定、外观、尺寸和专属内容设置。只有主动搜索天气城市时才发送输入的关键词；不会使用 IP、GPS、Wi-Fi 或设备位置。

- 分组盒底部“自动整理”会把当前用户桌面和公共桌面的直接子项放进各分组盒：在“桌面组件”页选中某个分组盒，可勾选它收纳的类型（文件夹、软件与快捷方式、文档、图片、视频、音乐、压缩包）或填写其他扩展名；没有盒子收纳的项目归入“软件与快捷入口”“桌面文件夹”“桌面文件”三个盒子。重复执行只补新增映射，并清除原文件已被删除的“已失效”映射（所在磁盘未连接或网络共享离线时保留）；“布局”页的“分组盒自动刷新”开关（默认关闭）开启后，分组盒监听映射所在目录与桌面目录：原文件被删除后确认已删除的映射自动移除，桌面上新出现的项目自动收纳进已有分组盒（不新建分类盒；下载中的临时文件按扩展名跳过，改名完成后才入盒）；不会移动、隐藏、重命名或删除桌面原文件。
- 未锁定卡片可直接拖动标题或非交互空白区域；要避免误拖时，在“桌面组件”页选中该卡片并开启“锁定卡片位置”。
- **卡片宽高在对应组件详情中输入**：待办支持今日列表与周历视图（`WeeklyView`，设置中心“桌面组件”页可设 `WeeklyWeekCount` 1–5 周，默认 4 周；跨月自动断行对齐星期列，内置 `ChineseLunisolarCalendar` 农历显示，1 周模式锚定本周、2–5 周模式含上周一）；列表视图仅展示周历今天格的任务（顶栏待办计数同口径），跨天后旧任务仍留在原日期供重新安排；文字始终可直接编辑，Enter 提交，Esc 放弃本次修改；空白行显示“输入待办…”提示，底部统计只计算写了内容的待办；“清理已完成”仅清理今日已完成项，保留其他日期历史，“隐藏已完成/显示已完成”同步过滤列表行、周历格内前 2 条预览、“还有 N 条 ▾”溢出计数与详情浮层；周历格单击选中、点“还有 N 条 ▾”或标题栏 `+` 弹出当日详情浮层 `DayPeek`（支持前一日/后一日切换、底部回车新增、双击行内编辑、指针悬停 300 ms 抬起后拖拽调序、右键移到明天/后天/大后天及单步撤销 Toast），双击格子打开无边框 `DayEditWindow` 多行序号文本编辑（未改动行按文本优先对齐作位置锚点，锚点区间内未认领条目按原位改字复用并保留 `Id`、完成状态与完成时间戳，区间外新增行创建为未完成新条目）。
- 每条待办右侧的“×”删除该条；右键可上移、下移或删除。
- 文件、文件夹、快捷方式或 URL 拖进桌面分组盒只记录路径；自动显示名隐藏快捷方式和程序后缀（.lnk、.exe 等，文档后缀保留，悬停可见完整路径），双击打开，右键可调整手动顺序、修改显示名称（不重命名原文件）、转移到其他分组盒或移除映射；原路径不存在时会标记为“已失效”，确认原文件已删除（所在磁盘可访问）的映射会自动清除，因磁盘未连接或网络共享离线而失效的映射保留，右键可重新定位到新路径或移除。
- 点击分组盒标题栏的“+”会打开添加菜单，可选择文件、文件夹，一次导入当前用户桌面与公共桌面的第一层项目，或添加此电脑、回收站、下载、桌面等系统入口；底部常驻“自动整理”按钮会按软件入口、文件夹和文件生成或补充分组盒。操作区会显示新增数量或没有新项目的结果；导入、整理与排序都不会移动、重命名或删除原文件。

搜索来源与入口：默认通过系统 ADODB / Search.CollatorDSO 读取 Windows 已有索引，以 System.ItemUrl 还原真实文件路径，避免本地化显示路径导致重复结果或无法打开；先按文件名词前缀和字面量条件查询，空结果且非短 ASCII 串时回退文件名包含查询；不读取正文，不修改系统服务或索引范围，不携带额外依赖。原有桌面与应用结果先同步显示，索引结果异步增量追加在下方（保持首阶段已显示行与选中项原位不跳变）；每次最多 128 个候选，最多一个原生查询，连接和命令超时为 1 秒，界面等待最长 900 ms（繁忙时入场等待最多 500 ms），旧查询取消且迟到结果不覆盖新输入。可选 Everything 可用时使用其索引，不可用时回退 Windows 索引，两者不可用仍保留基础搜索。个人配置 Schema v31 保存可选 Everything 开关（默认关闭）、顶栏居中/独立搜索框/图标模式，以及独立框的位置和宽度。Everything 使用官方 Unicode WM_COPYDATA 协议查询本机运行实例；不携带 SDK DLL，不启动 Everything，不维护索引。每次取回最多 128 个文件名候选，与基础候选按路径去重后追加在下方，展示上限仍为 24。只在非空输入 220 ms 去抖后查询，回复等待最多 600 ms，旧查询与会话关闭会取消等待；不可用时显示回退来源状态。独立框沿用同一输入、结果浮层与打开逻辑，宽度限制 240–800 DIP，复用工作区恢复。独立搜索框可选深色、浅色、跟随卡片或自定义底色，不透明度限制 5%–100%，圆角限制 0–24 DIP，文字按底色适配；结果列表和右键菜单按底色明暗使用不透明冰蓝底色与配套文字色，避免桌面内容透出，路径和快捷键保持次要层级，菜单项高度至少 34 DIP；v30 状态迁移到 v31 时保留入口与位置，外观默认深色、不透明度 94%、圆角 10 DIP。会话启动通过 WPF InputMethod 启用当前输入法的本地文字转换，输入中仍可切换英文；拼音组合期间暂停查询并关闭结果浮层。切换入口复用输入框，独立框与图标之间复用同一窗口；设置应用合并到当前输入事件结束后，保存复用现有 350 ms 去抖。以上个人设置均不进入主题包。协议按官方 SDK 文档独立实现，验证版本为 Everything 1.4.1.1032；Everything 主程序使用 MIT 许可，PCRE 等组件沿用各自许可，冰蓝不分发其程序、源码或 SDK 二进制。

图标读取由分组盒、应用选择器和搜索结果共享：优先保留真实高清帧；系统 Jumbo 图像列表仅在左上角填充旧图标时，回退到较小的系统图标帧，避免透明画布把图案缩成小点。原有居中留白保持不变，不修改快捷方式或系统图标。WPF 回归检查覆盖 16、32、48、64、128、256 像素源图标和冻结后的跨线程使用。

## 冰蓝 Dock 与任务栏验证

顶栏右侧的“托盘”按钮通过 `TrayOverflowController` 打开 Windows 原生隐藏图标面板；Windows 11 默认显示，模块开关可关闭，Windows 10 隐藏该入口。控制器由 `WidgetCoordinator` 按应用生命周期管理，按需挂接 Explorer 事件，面板关闭后停止轮询；重复请求不排队切换。关闭模块与应用退出复用同一次取消和清理，退出先确认浮层关闭，未确认时由用户选择继续退出或保留应用重试。按钮不改变自动隐藏设置，面板位置由 Windows 管理，Dock 在面板处于前台时收起。个人配置 Schema v33 将已有顶栏的托盘模块初始化为开启，保留顶栏总开关及其他模块设置；模块开关随顶栏主题字段导入导出。

隔离验收入口 `--shell-surfaces-preview` 与正式入口复用控制器，附加 `--tray-corners` 检查两角唤出；`--tray-slow-uia=<毫秒>` 仅在验收时模拟调用前延迟。v0.2.42 安装版和免安装版包含顶栏托盘入口，独立工具用于兼容性验收。兼容范围、观察结果与未覆盖场景见 [顶栏与系统入口验证](TOPBAR-QA.md)。

正式 Dock 的真机结果、资源占用和已知限制见 [冰蓝 Dock 真机验证](DOCK-QA.md)；本机单屏 125% 下的点击、固定、排序、最大化、全屏、智能隐藏、Explorer 重启和强制结束恢复均已通过，多显示器与混合缩放尚未覆盖。阶段 0 隔离实验、ManagedShell 取舍和四边 AppBar 记录保留在 `design-lab/BingLan.DockSpike/README.md`。任务栏透明、模糊、自动隐藏、崩溃恢复和桌面模式的真机结果见 [Windows 任务栏适配真机验证](TASKBAR-QA.md)。清爽桌面的恢复协议与真机结果见 [清爽桌面技术设计与恢复协议](DESKTOP-CLEAN-MODE-TECHNICAL-DESIGN.md)。
