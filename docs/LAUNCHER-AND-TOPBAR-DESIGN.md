# 启动面板与任务栏边位

## 启动面板

从冰蓝 Dock 的「打开启动面板」按钮或托盘菜单打开。面板位于指针所在显示器的工作区中上部，窄屏时随工作区缩小。顶部提供搜索、材质快切和关闭，左侧提供应用、用途类别、文件和「我的分组」导航。主体保留应用真实图标和名称，连续滚动。系统玻璃不可用时使用对应底色，高对比度模式使用系统颜色。

启动面板外观默认跟随全局配色和玻璃浓度，冰蓝默认浓度为 46%。右上角可在磨砂与清透之间快切。在「外观样式 → Dock、启动面板与顶端信息条外观」中可设置自定义底色、浓度和圆角。设置保存在本机，切回跟随后保留上一次自定义值。

```text
┌──────────────────────────────────────────────┐
│ 搜索应用、文件和文件夹              磨砂  × │
├────────────┬─────────────────────────────────┤
│ 应用概览   │ 常用                       筛选 │
│ 全部应用   │ 图标   图标   图标   图标       │
│ 办公协作   │                                 │
│ 浏览与沟通 │ 办公协作                        │
│ 地图与工程 │ 图标   图标   图标   图标       │
│ ……         │                                 │
│ 文件       │ 地图与工程                      │
│ 我的分组 + │ 图标   图标   图标   图标       │
│ 项目资料   │                                 │
│ 辅助入口   │             连续滚动            │
└────────────┴─────────────────────────────────┘
```

1. **打开。** 焦点进入搜索框。应用概览顶部显示一行可用的 Dock 固定应用，下方按用途分段。左侧用途类别只显示对应应用，「我的分组」可混合应用、文件和文件夹。相同目标、启动参数和工作目录的入口合并，来源可从「筛选」中选择。
2. **搜索。** 输入后显示紧凑的类型切换和范围选项，默认跨类型和分组搜索，当前范围优先。可切换类型、限定当前范围或选择来源。系统索引或已启用的 Everything 补充结果。清空查询回到之前的浏览范围与滚动位置。
3. **打开项目。** 单击或按 Enter 打开，方向键在网格中选择，Ctrl+1／2 切到应用或文件，Ctrl+Tab 在两类间切换。文件失效或响应超时时，面板保留并显示状态。输入法组合期间，候选选词键由输入法处理。
4. **整理项目。** 「我的分组」旁可新建分组。右键或按菜单键、Shift+F10，将入口加入分组、移出当前分组、固定到 Dock 或发送到桌面分组盒。一个入口可加入多组。应用的「更改类别」保存手动归类，「恢复自动分类」重新使用本机规则。操作结果在面板底部显示。
5. **收起。** 按 Esc、再次触发入口或切到其他窗口。面板与玻璃同步淡入淡出，并响应系统动画设置。菜单打开时优先关闭菜单。目标屏有真实全屏窗口时保持收起。

用途归类使用可执行文件和已知应用身份等本机规则，手动指定的类别优先。未识别的应用放在「未分类」。安装、升级、诊断等辅助入口从左侧「辅助入口」访问，也可通过搜索找到。应用概览按普通用途展示，个人类别覆盖保存在本机。

## 发送到分组盒

Dock 固定项和启动面板里的可映射项目可以发送到指定分组盒。目标通过盒子标识查找。同一盒中已有的项目只保留一份引用。右键操作保留原文件和 Dock 固定状态。失效路径、已移除的分组盒和重复发送各有对应提示。需要保留专用启动参数的入口继续通过原入口打开。

## 任务栏边位

「顶栏底栏 → Windows 任务栏」提供系统任务栏设置入口。可以确认时显示主显示器的任务栏边位。Windows 负责换边，冰蓝按各显示器工作区和可确认的任务栏矩形调整 Dock、顶端信息条和启动面板，顶边重叠时释放冰蓝自己的预留条。底部两角唤出仅适用于已确认的底边自动隐藏栏。

## 顶栏胶囊（实验暂停）

当前版本使用普通顶栏。居中胶囊保留在测试场景中。

## 验收场景

- 四边任务栏，主副屏和混合缩放。换边前后 Dock 和顶栏无重叠，最大化使用正确工作区，Explorer 重建后恢复。
- 通过 Dock 和托盘打开、再次触发、Esc 关闭。全屏应用保持前台。中文输入法选词和取消组合后，结果可以继续上下选择。
- 同程序同参数多来源合并，启动参数不同仍可分别打开。快速连续输入时保留当前查询结果。断开的网络位置及时提示，界面可以继续使用。
- 同一入口加入两个面板分组。移出当前分组后，另一组仍有此入口。默认搜索跨组，切换范围后按当前分组筛选。
- 应用概览按用途分段连续滚动。图标、行高和分类标题采用紧凑尺寸，名称最多显示两行。进入类别后只显示对应项目，文件导航和混合内容的自建分组各自显示完整内容。
- 修改应用类别后立即更新，重启后保留。恢复自动分类后按本机规则显示。未识别应用和辅助入口均可从导航与搜索访问。
- 从滚动后的类别输入查询，切换结果类型和范围后清空，恢复原浏览类别与位置。
- 右键固定到 Dock 保留启动参数与工作目录。清透和磨砂快切后保留选择。
- 发送现有文件，盒内出现一条映射。重复发送、删除目标盒和路径失效有对应状态。磁盘上原文件仍在原处。
- 发送进入路径检查后删除目标盒。两个入口共用的发送流程返回「该分组盒已移除」，被删除的分组盒没有新增映射，原文件内容保持一致。
- 调整启动面板底色、浓度和圆角，重新打开后生效，重启后保留。切回跟随后使用全局外观。
