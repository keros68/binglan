# 冰蓝总览卡与任务栏边位

## 冰蓝总览卡

从冰蓝 Dock 的「打开冰蓝总览卡」按钮、托盘菜单、顶端信息条居中搜索入口或全局热键（默认 `Ctrl+Alt+F`，由独立消息窗口注册，不依赖顶端信息条是否开启）打开并聚焦搜索框。可在「设置 → 冰蓝总览卡」开启或关闭，并统一配置全局呼出热键（可清空停用）、弹出背景方式、常用星标来源、最近使用文件与「使用 Everything 搜索文件」，默认开启。关闭后收起面板，隐藏 Dock、托盘和顶端信息条上的入口并注销总览卡热键。面板位于指针所在显示器的工作区居中位置，宽高按当前显示器的 DPI 无关工作区比例自适应（横屏 760–1080 × 480–720 DIP，竖屏 520–900 × 520–820 DIP，并保留四周安全边距）。顶部提供搜索、主入口（搜索态展开「全部」，平时并列「应用 / 文件 / 我的分组」）、材质快切、「固定并置顶」图钉（钉住后临时置顶，切到其他软件或打开条目时不自动收起；支持拖动顶部/边缘空白处移到屏幕一侧，双击空白处归位居中，取消固定或关闭即恢复普通层级）和关闭，左侧导航随当前主入口切换。面板记住上次停留的主标签与视图偏好；文件页支持收藏自定义常用文件夹（上限 16，不进主题包），结果项支持拖出文件（拖动期间面板自动透明穿透以便直接落到下方软件）、`Ctrl+C` 复制文件、本机打开频次加权排序与被动 QuickLook 空格预览。主体保留应用与文件真实图标和名称，支持连续滚动虚拟化网格与详细列表。系统玻璃不可用时使用对应底色，高对比度模式使用系统颜色。

冰蓝总览卡外观默认跟随全局配色和玻璃浓度，冰蓝默认浓度为 46%。右上角可在磨砂与清透之间快切。在「设置 → 冰蓝总览卡 → 外观与材质」中可设置自定义底色、浓度和圆角。设置保存在本机，切回跟随后保留上一次自定义值。

1. **打开与记忆。** 焦点进入搜索框，并恢复上次停留的主标签（应用 / 文件 / 我的分组）。应用页「全部应用」顶部显示一行可用的 Dock 固定应用，下方支持「按分类」和「A–Z」切换。相同目标、启动参数和工作目录的入口合并，来源可从「筛选」中选择。
2. **文件页与目录展开。** 「文件」为与「应用」同等权重的主视图：顶部展示常用位置（桌面、下载、文档、图片）与冰蓝桌面分组盒快捷卡片，下方展示最近使用文件（默认开启，只读读取 Windows Recent，可在总览卡和「设置 → 冰蓝总览卡」随时关闭）及已收录文件；左侧提供文件总览、最近使用（按今天/本周/更早分段）、按文件形态（文件夹、文档、图片、影音、压缩包）和常用位置/分组盒导航。单击位置卡片或文件夹可在总览卡内只读展开子项（带返回按钮、面包屑、`Alt+Left` 返回、图标/列表视图切换和「打开目录」按钮），不移动或修改原文件。
3. **搜索。** 输入后顶部标签栏左侧展开「全部」，四个顶部标签直接筛选当前搜索结果且不清空搜索框；底栏来源筛选旁显示「仅搜当前范围」，默认跨类型和分组搜索且当前范围优先。系统索引或已启用的 Everything 补充结果。清空查询隐藏顶部「全部」标签并回到之前的浏览标签、分类与滚动位置。
4. **打开项目。** 浏览模式初始不默认选中项目（按方向键、`Home`/`End` 或右键选中后显示框选边框），搜索态默认选中首条匹配。`Left`/`Right` 仅焦点位于结果区或搜索框为空时移动选择，`Up`/`Down`/`PageUp`/`PageDown` 在搜索框或结果区内移动选择（搜索框内容为空时支持 `Home`/`End` 跳至首末项）。单击或按 Enter 打开选中项（文件页内单击普通文件夹为面板内展开，右键可选「在资源管理器中打开」），Ctrl+1／2／3 切到应用、文件或我的分组，Ctrl+Tab 循环切换（搜索态含「全部」）。文件失效或响应超时时，面板保留并显示状态。输入法组合期间，候选选词键由输入法处理。
5. **整理项目。** 「我的分组」支持应用、文件和文件夹跨类型混排（网格视图自动分段，列表视图统一呈现）。右键或按菜单键、Shift+F10，将入口加入分组、移出当前分组、固定到 Dock 或发送到桌面分组盒。一个入口可加入多组；自建分组可在分组页头部或左侧导航右键菜单就地重命名及二次确认删除（仅移除分组，不影响原文件）。应用的「更改类别」保存手动归类，「恢复自动分类」重新使用本机规则。操作结果在面板底部显示，常规浏览状态不重复显示数量摘要。
6. **收起。** 按 Esc、再次触发入口或切到其他窗口，立即收起面板和玻璃。菜单打开时优先关闭菜单。目标屏有真实全屏窗口时保持收起。

用途归类采用 7 个通用大类（效率办公、通讯与浏览、影音娱乐、设计与创作、开发工具、游戏、系统与工具）加「其他」和「辅助入口」，使用可执行文件、打包应用身份和开始菜单目录等本机规则保守识别。自动识别不足 3 项的小类自动折叠归入「其他」以减少零碎分段；手动指定的类别始终优先并独立显示，未识别的应用放在「其他」。安装、升级、诊断等辅助入口从左侧「辅助入口」访问，也可通过搜索找到。个人类别覆盖与浏览偏好均保存在本机，不进入主题包。

## 发送到分组盒

Dock 固定项和冰蓝总览卡里的可映射项目可以发送到指定分组盒。目标通过盒子标识查找。同一盒中已有的项目只保留一份引用。右键操作保留原文件和 Dock 固定状态。失效路径、已移除的分组盒和重复发送各有对应提示。需要保留专用启动参数的入口继续通过原入口打开。

## 任务栏边位

「顶栏底栏 → Windows 任务栏」提供系统任务栏设置入口。可以确认时显示主显示器的任务栏边位。Windows 负责换边，冰蓝按各显示器工作区和可确认的任务栏矩形调整 Dock、顶端信息条和冰蓝总览卡，顶边重叠时释放冰蓝自己的预留条。底部两角唤出仅适用于已确认的底边自动隐藏栏。

## 顶栏胶囊（实验暂停）

当前版本使用普通顶栏。居中胶囊保留在测试场景中。

## 验收场景

- 四边任务栏，主副屏和混合缩放。换边前后 Dock 和顶栏无重叠，最大化使用正确工作区，Explorer 重建后恢复。
- 通过 Dock、托盘、顶端信息条居中搜索按钮或全局热键打开/收起并聚焦搜索框；关闭「冰蓝总览卡」后隐藏顶栏入口并注销热键，重新开启后恢复原设置。全屏应用保持前台。中文输入法选词和取消组合后，结果可以继续上下选择。
- 同程序同参数多来源合并，启动参数不同仍可分别打开。快速连续输入时保留当前查询结果。断开的网络位置及时提示，界面可以继续使用。
- 同一入口加入两个面板分组，并在界面内联重命名与二次确认删除分组（不影响原文件）；移出当前分组后，另一组仍有此入口。搜索时顶部出现「全部」并可点顶部标签直接筛选而不清空输入；底栏「仅搜当前范围」与来源筛选并排工作。
- 应用概览按用途分段连续滚动，常规浏览不重复显示数量摘要，初始无默认高亮选中，焦点位于其他顶部按钮时不抢占方向键，方向键/`Home`/`End` 后显示框选边框。图标、行高和分类标题采用紧凑尺寸，名称最多显示两行。进入类别后只显示对应项目，文件导航和混合内容的自建分组各自显示完整内容。
- 修改应用类别后立即更新，重启后保留。恢复自动分类后按本机规则显示。未识别应用和辅助入口均可从导航与搜索访问。
- 从滚动后的类别输入查询，切换顶部结果标签和范围后清空，隐藏顶部「全部」并恢复原浏览标签、类别与滚动位置。
- 右键固定到 Dock 保留启动参数与工作目录。清透和磨砂快切后保留选择。
- 发送现有文件，盒内出现一条映射。重复发送、删除目标盒和路径失效有对应状态。磁盘上原文件仍在原处。
- 发送进入路径检查后删除目标盒。两个入口共用的发送流程返回「该分组盒已移除」，被删除的分组盒没有新增映射，原文件内容保持一致。
- 调整冰蓝总览卡底色、浓度和圆角，重新打开后生效，重启后保留。切回跟随后使用全局外观。
