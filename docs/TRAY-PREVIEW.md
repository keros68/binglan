# 托盘兼容性验收工具

v0.2.29 是预发布版，安装版和免安装版均提供顶栏“托盘”按钮。`BingLan-0.2.29-tray-preview.zip` 是独立兼容性验收工具，用于在 Windows 11 x64 上检查原生隐藏图标面板的唤出、关闭和任务栏恢复。该工具自带 .NET 运行时，无需安装或管理员权限。

## 使用

1. 先退出正在运行的冰蓝桌面，再把压缩包完整解压到可写目录。
2. 运行 `BingLan-TrayPreview\BingLan.TrayPreview.exe`。工具显示临时顶栏、Dock 和验收窗口，使用独立临时配置。
3. 点击“临时自动隐藏任务栏”，再分别检查“托盘连点实验”“托盘循环20次”“故障恢复实验”“托盘保持与焦点切换”。等待一项完成后再运行下一项，运行期间不要点击验收窗口。
4. 点击“托盘打开后退出”，检查浮层消失、任务栏恢复到启动工具前的设置。重新运行工具后，可检查“唤出中退出”。
5. 如需测试仅从底部两角唤出，可在工具目录运行 `BingLan.TrayPreview.exe --tray-corners`，再重复上述步骤。

验收失败时，窗口会显示失败信息；可点击“恢复启动前任务栏设置”或重试退出。正常退出后，临时配置目录会被清理。工具被强制结束或异常退出后，下次启动会先恢复上次临时修改的任务栏设置，日志中记为 `RECOVERED`。同一时间只能运行一个验收窗口。工具不改写冰蓝桌面的正式个人配置，不创建开机启动项，也不自动上传结果。

原生调用长时间无响应时，退出会提示清理未完成；可稍后重试。连续两次仍未完成时，第三次退出会放弃等待并在日志中记为 `EXIT-ABANDONED`，此时请检查屏幕右下角的托盘浮层是否已关闭。

## 反馈

日志保存在工具目录的 `artifacts\tray-preview-*.log`，截图位于 `artifacts\shell-surfaces\`。截图包含屏幕右下角的实际内容，分享前请检查隐私信息。

反馈时请说明 Windows 版本、显示器数量、缩放比例、失败的按钮和现象，并附相关日志。截图按需提供。

## 验证范围

已验证 Windows 11 25H2 Build 26200.9711、中文系统、单显示器 2560×1440、125% 缩放下的正常开合、重复请求、连续失败恢复、切窗保留焦点（包括切换到其他程序）、Esc 关闭、托盘图标右键菜单保留焦点、正常退出、UIA 工作任务启动后在实际调用按钮前取消、模拟调用延迟时的退出重试，以及通过模拟遗留记录验证下次启动恢复。

实际按钮调用进入提供程序后的迟到结果、其他 Windows Build、非中文系统、多显示器、混合 DPI、全屏、Explorer 重建，以及真实的 `taskkill /F` 强制结束尚未验证。异常结束后未重新运行工具时，可在 Windows 设置 → 个性化 → 任务栏 → 任务栏行为中恢复“自动隐藏任务栏”。Windows 10 上托盘按钮不执行。

## 从源码打包

```powershell
pwsh -NoProfile -File .\installer\build-tray-preview.ps1 -Version 0.2.29
```

此命令只为验收包选择独立启动入口，不改变常规测试入口或正式程序。

验收窗口还提供“顶栏托盘入口”和“顶栏托盘打开后退出”，调用正式顶栏按钮与应用退出命令，使用同一个应用宿主管理面板清理。
