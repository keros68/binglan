# 托盘兼容性验收工具

v0.2.28 是预发布版。常规程序仍不提供独立托盘入口；`BingLan-0.2.28-tray-preview.zip` 用于在 Windows 11 x64 上测试原生隐藏图标面板的唤出、关闭和任务栏恢复。该工具自带 .NET 运行时，无需安装或管理员权限。

## 使用

1. 先退出正在运行的冰蓝桌面，再把压缩包完整解压到可写目录。
2. 运行 `BingLan-TrayPreview\BingLan.TrayPreview.exe`。工具显示临时顶栏、Dock 和验收窗口，使用独立临时配置。
3. 点击“临时自动隐藏任务栏”，再分别检查“托盘连点实验”“托盘循环20次”“故障恢复实验”“托盘保持与焦点切换”。等待一项完成后再运行下一项。
4. 点击“托盘打开后退出”，检查浮层消失、任务栏恢复到启动工具前的设置。重新运行工具后，可检查“唤出中退出”。
5. 如需测试仅从底部两角唤出，可在工具目录运行 `BingLan.TrayPreview.exe --tray-corners`，再重复上述步骤。

验收失败时，窗口会显示失败信息；可点击“恢复任务栏”或重试退出。正常退出后，临时配置目录会被清理。工具不改写冰蓝桌面的正式个人配置，不创建开机启动项，也不自动上传结果。

## 反馈

日志保存在工具目录的 `artifacts\tray-preview-*.log`，截图位于 `artifacts\shell-surfaces\`。截图包含屏幕右下角的实际内容，分享前请检查隐私信息。

反馈时请说明 Windows 版本、显示器数量、缩放比例、失败的按钮和现象，并附相关日志。截图按需提供。

## 验证范围

已验证 Windows 11 25H2 Build 26200.9711、中文系统、单显示器 2560×1440、125% 缩放下的正常开合、重复请求、连续失败恢复、切窗保留焦点、正常退出和调用原生按钮之前的取消。

其他 Windows Build、多显示器、混合 DPI、全屏、Explorer 重建、调用按钮后的取消和强制结束进程尚未验证。工具被强制结束时不能保证自动恢复；必要时在 Windows 设置 → 个性化 → 任务栏 → 任务栏行为中恢复“自动隐藏任务栏”。Windows 10 暂不用于此项验收。

## 从源码打包

```powershell
pwsh -NoProfile -File .\installer\build-tray-preview.ps1 -Version 0.2.28
```

此命令只为验收包选择独立启动入口，不改变常规测试入口或正式程序。
