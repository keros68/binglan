# 外观试选与竖屏布局设计

日期：2026-10-26
范围：本地实现、自动验证与独立视觉验收；不包含提交、发布或安装。

## 1. 目标与依据

在设置中心试选卡片外观，确认后应用；布局预设在竖屏中保持可用。沿用 .NET 10、WPF 和冰蓝视觉语言，不增加依赖或常驻服务。

当前实现依据：

- `SettingsWindow` 的卡片材质、配色、浓度和文字颜色即时修改共享状态，通过 `SettingsMaintenance.ApplyGlass` 应用。
- `DesktopStyleRules` 已定义六套配色、材质、文字和 Dock 配色计算，可直接复用。
- `ThemePreviewRenderer` 使用通用标签和矩形绘制示意图；预设预览与实际应用均调用 `DesktopExperienceRules.PresetPlacements`。
- 预设位置按横屏组织，问候语等宽元素在窄竖屏上不能保持原构图。

参考 DeskMakeover 的试选、对比和横竖屏独立构图原则。参考版本为 `0bdd2ccfbcc24dfd71754f320ccf380e9b34c8c8`；不复制其代码或资源。

## 2. 外观试选

### 2.1 入口与操作

在设置中心“外观”的“卡片外观”区域提供“试选外观…”入口，打开由设置窗口拥有的模态 WPF 窗口。现有快捷控件保持即时应用。

窗口包含示例预览、材质、现有六套配色、玻璃浓度、文字颜色（跟随、白色、深色、自定义），以及“查看原效果”“应用”“取消”。使用与设置中心一致的资源和可访问名称。

- 打开时复制当前外观，形成独立草稿；不持有可以修改正式状态的嵌套引用。
- 所有试选只更新草稿及预览，不保存、不调用真实应用回调、不触碰桌面窗口。
- 对比按钮切换当前外观与草稿预览，文字清晰反映当前状态；支持键盘，不采用必须持续按住鼠标的交互。
- “应用”只回写材质、配色、浓度、文字模式和自定义文字色，并走现有 `ApplyGlass` 一次。保留间距、动效、强调色、Dock 独立外观以及个人内容；阴影沿用已有规则，无底板且原阴影为“无”时自动使用柔和阴影，预览同步体现。
- 取消、Esc、标题栏关闭与父窗口关闭均丢弃草稿。没有修改时应用为无操作，避免重新覆盖用户单独定制的卡片。
- 不新增持久化字段，不改变主题包格式。暂不提供多步撤销；草稿取消和原效果对比满足本阶段需求。

### 2.2 预览内容与边界

预览标注“示例预览”，用固定时间、天气、性能、待办、文件图形和通用 Dock 符号展示材质与文字层级；不读取用户城市、姓名、待办、文件名、图标或壁纸。不启动天气、性能、音频、Shell 枚举等运行服务。

预览配色必须来自 `DesktopStyleRules.Appearance` 等现有规则，不能另写第二套近似颜色表。复用已有可脱离窗口使用的 WPF 资源/控件；若现有窗口与后台服务耦合，则使用无副作用的 WPF 示例视图，不实例化正式宿主窗口。

预览可在浅、深背景中检查文字对比，背景仅在试选窗口使用。无底板、极低浓度和自定义文字颜色均应可辨认其实际效果，不强行改写用户颜色。玻璃采用静态示意，不声称与 Windows 实时模糊逐像素一致。

预览只在参数变化时更新；拖动浓度可合并刷新，不建立持续计时器。限制内容在容器内，窗口缩小或高缩放时允许滚动，底部动作保持可访问。

本阶段保留主题包的隐私安全示意预览，不把桌面截图写入主题包，也不扩展为完整桌面编辑器。

## 3. 竖屏布局

继续使用现有四种 `DesktopLayoutPreset`，不增加枚举或迁移。只有工作区高度大于宽度时使用竖屏构图；横屏现有行为保持不变。

- 在 `DesktopExperienceRules.PresetPlacements` 的共同路径中生成竖屏位置，预览、首次引导和真实应用共用。
- 竖屏以居中的纵向信息层次安排时间、天气、性能、待办和问候，保留各预设的主要侧重点，避免横屏元素简单压缩后重叠。
- 位置以传入工作区为准，支持负坐标；边距和间距明确，宽度不超过可用工作区。
- 在常用竖屏工作区 720×1280、864×1536、1080×1920 DIP 下，五张预设卡片均位于工作区内且不相互重叠，至少满足现有信息卡 180×72、待办 226×166 DIP 的下限。
- 极小工作区以可见性优先并复用恢复策略；不能承诺在不足以容纳最小卡片时仍全部无重叠。实现旁注明这一上限。
- 不改变显示开关、锁定、个人内容、用户手动位置或已保存的其他显示器排列；仅在用户应用预设时使用新构图。
- 预设预览按所用工作区比例显示，不把竖屏强制拉伸为 16:9。设置页缩略图在外观或工作区变化后更新，不能永久保留首次渲染缓存。

## 5. 验收

### 自动验证

1. 打开、试选、对比、取消、Esc 和关闭均不改变原状态，不触发应用回调。
2. 应用只提交指定外观字段，一次调用现有应用路径；再次打开读到已应用值；未修改则不调用。
3. 保留个人内容和未授权样式字段；固定示例内容不受带有唯一敏感标记的用户数据影响。
4. 六配色、三材质、浓度边界、文字模式的预览使用现有规则；窗口构造与关闭不启动后台采样。
5. 四种预设在上述竖屏工作区及负坐标工作区内，尺寸有效、边界有效、互不重叠；代表性横屏坐标保持不变。
6. 预览与应用调用同一布局函数；刷新不保留旧配色/旧比例。现有主题包往返与隐私测试保持通过。

```powershell

```

### 视觉与交互验收

使用隔离测试状态打开真实 WPF 试选窗口，检查浅色、深色、无底板、自定义文字、对比和取消；捕获并检查成品图。检查小窗口和高缩放下的内容边界与按钮访问。

竖屏布局用指定 DIP 工作区进行规则与绘制验证；若没有真实竖屏或混合 DPI 显示器，明确记录未完成真机覆盖，不能将模拟坐标检查写成实机通过。
