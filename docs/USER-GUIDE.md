# 冰蓝桌面使用说明

冰蓝桌面是 Windows 11 的桌面伴侣：在桌面上显示时间、天气、电脑性能、待办和便签，用分组盒整理桌面入口，并可选用冰蓝 Dock 和任务栏外观。所有数据只保存在本机。

## 开始使用

1. 安装后启动冰蓝桌面，首次会显示引导：选择布局、称呼和天气城市、固定到 Dock 的常用应用、桌面模式。每一步都可以跳过，之后在设置中心修改。
2. 引导结束后，桌面上会出现时间、问候、天气、性能、一个待办便签和一个分组盒。
3. 通知区域（屏幕右下角）有冰蓝桌面图标：双击打开设置中心，右键打开菜单。

免安装版把 zip 解压到任意文件夹后运行其中的 `BingLan.exe` 即可，效果与安装版相同，个人数据也保存在同一位置。免安装版更新时请重新下载 zip 覆盖，不要使用应用内“下载并安装”（它安装的是安装版）；免安装版和已安装版不要同时运行。删除文件夹前先退出程序；若开启了“登录时启动”，先在设置里关闭。

## 设置中心

Windows 11 开启系统“透明效果”时，Dock 和隐藏把手会实时模糊背后的桌面内容，收起和展开时毛玻璃跟随圆角轮廓变化。关闭系统透明效果、启用高对比度或系统不支持时，自动使用半透明背景。桌面卡片保持原有材质。

打开方式任选其一：

- 双击通知区域的冰蓝桌面图标；
- 单击任一卡片，点击卡片上出现的设置按钮；
- 用 Tab 键把焦点移到卡片上，点击出现的设置按钮；
- 右键卡片，选择“在冰蓝桌面中设置…”。

设置修改后立即生效，无需保存：输入框在停顿片刻、按回车或离开输入框后生效；布局预设选好后点击“应用布局”。“通用”页底部的“退出冰蓝桌面”用于退出程序。

| 页面 | 用途 |
| --- | --- |
| 外观 | 桌面模式（一次设置 Dock 和任务栏）、清爽桌面、卡片外观（浅色玻璃配色、深色玻璃、无底板、玻璃浓度、文字颜色、文字阴影、吸附间距）、布局预设（卡片摆放位置）、导出和导入主题包 |
| 桌面组件 | 新建待办便签、普通便签、分组盒；调整每张卡片的锁定、尺寸和外观。时间、问候、天气、性能和待办可以隐藏，便签和分组盒不用时可以删除 |
| Dock | 开启冰蓝 Dock，选择显示器、显示方式和动效，管理固定应用和 Windows 开始菜单入口 |
| 任务栏 | 任务栏保持默认、透明、模糊或自动隐藏；自动隐藏时可从底边唤出，也可只在角落唤出；有新消息时不弹出 |
| 通用 | 登录时启动，检查和安装新版本，备份与恢复，查看数据位置和联网范围，退出程序 |

## 常用操作

顶栏右侧提供“托盘”按钮，可打开 Windows 隐藏图标面板，再点一次收起；在“顶端信息条”的模块设置中可关闭。面板仍由 Windows 管理，关闭面板后任务栏按原设置收回。面板的弹出位置由 Windows 决定，多显示器时出现在主显示器右下角。前台是管理员程序（如任务管理器）时，Windows 不允许普通程序向它发送快捷键，冰蓝会提示先切换到其他窗口。Windows 10 隐藏该按钮；入口不可用时可将鼠标移到屏幕底边或角落访问原生任务栏。

- **移动卡片**：拖动卡片标题或空白处；拖动卡片边缘或四角可调整大小。靠近其他卡片时会自动对齐，按住 Alt 拖动可暂时关闭对齐。在“桌面组件”页勾选“锁定卡片位置”后不会被误拖。
- **单张卡片外观与字体**：在“桌面组件”页选中卡片，点“浅色玻璃 / 深色玻璃 / 无底板”只改这一张；字体列表最前面是内置字体（得意黑、Jost、Quicksand），时间卡片选“Jost 极细”可得到细长的大号时钟。
- **修改标题**：双击待办、便签或分组盒的标题，或选中卡片后按 F2；Enter 确认，Esc 放弃。
- **待办**：可在标题栏切换“列表 / 周历”视图。列表视图直接输入，Enter 确认，Esc 放弃本次修改；勾选方框标记完成，点击右侧“×”删除该条，右键可上移、下移。周历视图按周一至周日展示（带农历初一月份与每日农历标注，可在设置中心“桌面组件”页选中待办卡片将显示周数调为 1–5 周，默认 4 周）；单击选中格子后点标题栏“+”或点击格内“还有 N 条 ▾”展开当日详情浮层，可在浮层底部回车新增、双击条目文字原地修改、指针悬停 0.3 秒抬起后拖拽调序，或右键“移到 ▸ 明天/后天/大后天”（底部弹出提示条可一键撤销）；双击任意日期格可打开单日多行编辑窗，回车自动续编序号，点击“✓”或关闭窗口自动保存。
- **便签**：直接输入文字；单击便签后点击标题栏的“Aa”，可设置正文字体、字号、颜色、粗斜体和对齐。
- **分组盒**：把文件、文件夹或快捷方式拖进分组盒，只记录位置，原文件不会移动。双击打开；右键可修改显示名称（不重命名原文件）或转移到其他分组盒；在设置“布局”页开启“分组盒自动刷新”（默认关闭）后，桌面上新出现的文件自动收纳进已有的分组盒（下载中的临时文件等改名完成后才入盒），原文件被删除后对应项自动从盒中清除；因 U 盘或网络盘未连接而暂时找不到的项会保留并显示“已失效”，右键可重新定位。“自动整理”会把桌面项目放进各分组盒，并顺带清除残留的“已失效”项；在设置中心“桌面组件”页选中分组盒，可勾选它收纳的类型（如文档、图片、压缩包）或填写其他扩展名，自定义自己的收纳盒。
- **清爽桌面**：在“外观”页打开“清爽桌面”。开启前会在分组盒中加入此电脑、回收站、下载和桌面入口；关闭或退出后图标恢复。
- **Dock 应用**：Dock 左端默认显示 Windows 开始菜单入口，可在“Dock”页关闭。单击打开 Windows 原生开始菜单，右键打开原生系统快捷菜单（Win+X）；系统菜单打开时 Dock 暂时收起。按住 Shift 或 Ctrl 点击开始入口同样会打开开始菜单；前台是管理员程序时，右键菜单会提示先切换到其他窗口。在 Dock 页点击“导入任务栏应用”可导入任务栏上固定的应用。把程序、快捷方式或分组盒里的软件图标拖到 Dock 上可固定；正在运行的应用拖到 Dock 左侧的固定段也会固定。右键 Dock 空白处或在设置中心“Dock”页点“添加应用…”，会列出开始菜单里的应用，搜索后勾选即可。右键固定的应用可更换图标或取消固定。图标大小和外观在设置中心“Dock”页调整：外观默认跟随卡片，选“自定义”后可选配色或任意颜色，并调整不透明度。微信等应用来消息时，Dock 图标右上角会出现橙色标记；不想让隐藏的任务栏因此弹出，在“任务栏”页打开“有新消息时不弹出任务栏”。
- **顶端系统状态**：点击电量、网络或音量会打开 Windows 快速设置，再点一次收起；快速设置确实无法打开时才分别打开对应的 Windows 设置。点击输入法会打开 Windows 输入法选择器，入口不可用时打开语言设置。信息条只显示状态，不在其中调节系统设置或切换输入法。
- **任务栏只在角落弹出**：任务栏设成自动隐藏后，鼠标移到底边可唤出原生任务栏。在设置中心“任务栏”页打开“鼠标仅从底部两角唤出”后，鼠标碰到底边中间不会再弹出任务栏。该选项只限制鼠标唤出；打开开始菜单等系统面板时，Windows 仍可能显示任务栏。
- **搜索文件与应用**：开启顶端信息条后，可在该设置页选择顶栏居中、独立搜索框或顶栏图标。独立框左侧手柄用于拖动，右侧手柄用于调宽，位置和宽度自动保存；同页的“独立搜索框外观”可选择配色、底色、不透明度和圆角，并可恢复默认。搜索开始时使用当前输入法的本地文字模式，输入中可用 Shift 切换英文。默认搜索桌面、开始菜单与 Windows 已索引的文件名，无需安装 Everything。系统索引范围取决于 Windows 的设置，未索引目录不会被额外扫描；系统索引不可用时仍可搜索桌面与应用。先启动完整版 Everything，再勾选“使用 Everything”，可使用其文件名索引；不可用时自动回退 Windows 索引。单击结果或按 Enter 打开，Esc 收起；默认全局热键为 Ctrl+Alt+F。
- **隐藏全部卡片**：右键通知区域图标，选择“隐藏桌面组件”；再次选择可重新显示。

## 主题包

在“外观”页导出主题，可分享给别人。主题包包含卡片外观、布局、整体风格、Dock 应用和自定义图标，不包含称呼、城市、待办、便签、文件位置、壁纸、字体、Dock 开始菜单入口和显示器选择等本机设置。导入前可查看预览，导入时会先备份当前设置。

## 恢复与卸载

- 任务栏透明只在已验证的 Windows 版本上启用，不支持时会在设置页说明。TranslucentTB 等任务栏工具运行时，冰蓝桌面会让出任务栏。
- 退出冰蓝桌面后，任务栏和桌面图标恢复原样。透明背景在冰蓝异常退出后也会自动恢复；自动隐藏和桌面图标在下次启动时恢复。
- 若任务栏或桌面图标没有恢复：任务栏在 Windows 设置 > 个性化 > 任务栏中调整；桌面图标在桌面右键菜单“查看”中勾选“显示桌面图标”。
- 卸载时会询问是否删除个人数据，默认保留；选择删除时数据移到回收站。
- 数据保存在 `%LOCALAPPDATA%\BingLanWidgets`。

## 联网与隐私

联网只用于天气和检查更新。冰蓝桌面每天向 GitHub 查询一次最新版本号，不发送个人数据，可在“通用”页关闭；发现新版本时只提示，点“下载并安装”后才下载，安装时冰蓝桌面会暂时退出，装完自动重新打开。天气位置由你手动选择，不使用 IP、GPS 或 Wi-Fi 定位。冰蓝桌面不收集使用数据，也不上传待办、文件位置、应用列表或窗口标题。
