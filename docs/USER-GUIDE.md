# 冰蓝桌面使用说明

冰蓝桌面是 Windows 11 的桌面伴侣：在桌面上显示时间、天气、电脑性能、待办和便签，用分组盒整理桌面入口，并可选用冰蓝 Dock 和任务栏外观。所有数据只保存在本机。

## 开始使用

1. 安装后启动冰蓝桌面，首次会显示引导：选择布局、称呼和天气城市、固定到 Dock 的常用应用、桌面模式。每一步都可以跳过，之后在设置中心修改。
2. 引导结束后，桌面上会出现时间、问候、天气、性能、一个待办便签和一个分组盒。
3. 通知区域（屏幕右下角）有冰蓝桌面图标：双击打开设置中心，右键打开菜单。

免安装版把 zip 解压到任意文件夹后运行其中的 `BingLan.exe` 即可，效果与安装版相同，个人数据也保存在同一位置。免安装版更新时请重新下载 zip 覆盖，不要使用应用内“下载并安装”（它安装的是安装版）；免安装版和已安装版不要同时运行。删除文件夹前先退出程序；若开启了“登录时启动”，先在设置里关闭。

## 设置中心

打开方式任选其一：

- 双击通知区域的冰蓝桌面图标；
- 单击任一卡片，点击卡片上出现的设置按钮；
- 用 Tab 键把焦点移到卡片上，点击出现的设置按钮；
- 右键卡片，选择“在冰蓝桌面中设置…”。

设置修改后立即生效，无需保存：输入框在停顿片刻、按回车或离开输入框后生效；布局预设选好后点击“应用布局”。“通用”页底部的“退出冰蓝桌面”用于退出程序。

| 页面 | 用途 |
| --- | --- |
| 外观 | 桌面模式（一次设置 Dock 和任务栏）、清爽桌面、卡片外观（浅色玻璃配色、深色玻璃、无底板、玻璃浓度、文字颜色、文字阴影、吸附间距）、布局预设（卡片摆放位置）、导出和导入主题包 |
| 桌面组件 | 新建待办便签、普通便签、分组盒；调整每张卡片的锁定、尺寸和外观。时间、问候、天气、性能和待办可以隐藏，便签和分组盒不用时可以删除 |
| Dock | 开启冰蓝 Dock，选择显示器、显示方式和动效，管理固定应用 |
| 任务栏 | 任务栏保持默认、透明、模糊或自动隐藏；只在角落唤出；有新消息时不弹出 |
| 通用 | 登录时启动，检查和安装新版本，备份与恢复，查看数据位置和联网范围，退出程序 |

## 常用操作

- **移动卡片**：拖动卡片标题或空白处；拖动卡片边缘或四角可调整大小。靠近其他卡片时会自动对齐，按住 Alt 拖动可暂时关闭对齐。在“桌面组件”页勾选“锁定卡片位置”后不会被误拖。
- **单张卡片外观与字体**：在“桌面组件”页选中卡片，点“浅色玻璃 / 深色玻璃 / 无底板”只改这一张；字体列表最前面是内置字体（得意黑、Jost、Quicksand），时间卡片选“Jost 极细”可得到细长的大号时钟。
- **修改标题**：双击待办、便签或分组盒的标题，或选中卡片后按 F2；Enter 确认，Esc 放弃。
- **待办**：直接输入，Enter 确认，Esc 放弃本次修改；勾选方框标记完成；点击右侧“×”删除该条；右键可上移、下移。
- **便签**：直接输入文字；单击便签后点击标题栏的“Aa”，可设置正文字体、字号、颜色、粗斜体和对齐。
- **分组盒**：把文件、文件夹或快捷方式拖进分组盒，只记录位置，原文件不会移动。双击打开；右键可修改显示名称（不重命名原文件）或转移到其他分组盒；在设置“布局”页开启“分组盒自动刷新”（默认关闭）后，桌面上新出现的文件自动收纳进已有的分组盒（下载中的临时文件等改名完成后才入盒），原文件被删除后对应项自动从盒中清除；因 U 盘或网络盘未连接而暂时找不到的项会保留并显示“已失效”，右键可重新定位。“自动整理”会把桌面项目放进各分组盒，并顺带清除残留的“已失效”项；在设置中心“桌面组件”页选中分组盒，可勾选它收纳的类型（如文档、图片、压缩包）或填写其他扩展名，自定义自己的收纳盒。
- **清爽桌面**：在“外观”页打开“清爽桌面”。开启前会在分组盒中加入此电脑、回收站、下载和桌面入口；关闭或退出后图标恢复。
- **Dock 应用**：在 Dock 页点击“导入任务栏应用”可导入任务栏上固定的应用。把程序、快捷方式或分组盒里的软件图标拖到 Dock 上可固定；正在运行的应用拖到 Dock 左侧的固定段也会固定。右键 Dock 空白处或在设置中心“Dock”页点“添加应用…”，会列出开始菜单里的应用，搜索后勾选即可。右键固定的应用可更换图标或取消固定。图标大小和外观在设置中心“Dock”页调整：外观默认跟随卡片，选“自定义”后可选配色或任意颜色，并调整不透明度。微信等应用来消息时，Dock 图标右上角会出现橙色标记；不想让隐藏的任务栏因此弹出，在“任务栏”页打开“有新消息时不弹出任务栏”。
- **任务栏只在角落弹出**：任务栏设成自动隐藏后，在设置中心“任务栏”页打开“只在屏幕左下角或右下角唤出”，鼠标碰到底边中间就不会再弹出任务栏。
- **隐藏全部卡片**：右键通知区域图标，选择“隐藏桌面组件”；再次选择可重新显示。

## 主题包

在“外观”页导出主题，可分享给别人。主题包包含卡片外观、布局、整体风格、Dock 应用和自定义图标，不包含称呼、城市、待办、便签、文件位置、壁纸和字体。导入前可查看预览，导入时会先备份当前设置。

## 恢复与卸载

- 任务栏透明只在已验证的 Windows 版本上启用，不支持时会在设置页说明。TranslucentTB 等任务栏工具运行时，冰蓝桌面会让出任务栏。
- 退出冰蓝桌面后，任务栏和桌面图标恢复原样。透明背景在冰蓝异常退出后也会自动恢复；自动隐藏和桌面图标在下次启动时恢复。
- 若任务栏或桌面图标没有恢复：任务栏在 Windows 设置 > 个性化 > 任务栏中调整；桌面图标在桌面右键菜单“查看”中勾选“显示桌面图标”。
- 卸载时会询问是否删除个人数据，默认保留；选择删除时数据移到回收站。
- 数据保存在 `%LOCALAPPDATA%\BingLanWidgets`。

## 联网与隐私

联网只用于天气和检查更新。冰蓝桌面每天向 GitHub 查询一次最新版本号，不发送个人数据，可在“通用”页关闭；发现新版本时只提示，点“下载并安装”后才下载，安装时冰蓝桌面会暂时退出，装完自动重新打开。天气位置由你手动选择，不使用 IP、GPS 或 Wi-Fi 定位。冰蓝桌面不收集使用数据，也不上传待办、文件位置、应用列表或窗口标题。
