# 冰蓝桌面使用说明

冰蓝桌面是 Windows 11 的桌面伴侣：在桌面上显示时间、天气、电脑性能、待办和便签，用文件收纳盒整理桌面入口，并可选用冰蓝 Dock 和任务栏外观。所有数据只保存在本机。

## 开始使用

1. 安装后启动冰蓝桌面，首次会显示引导：选择布局、称呼和天气城市、固定到 Dock 的常用应用、桌面模式。每一步都可以跳过，之后在设置中心修改。
2. 引导结束后，桌面上会出现时间、问候、天气、性能、一个待办便签和一个文件收纳盒。
3. 通知区域（屏幕右下角）有冰蓝桌面图标：双击打开设置中心，右键打开菜单。

免安装版把 zip 解压到任意文件夹后运行其中的 `BingLan.exe` 即可，效果与安装版相同，个人数据也保存在同一位置。免安装版更新时请重新下载 zip 覆盖，不要使用应用内“下载并安装”（它安装的是安装版）；免安装版和已安装版不要同时运行。删除文件夹前先退出程序；若开启了“登录时启动”，先在设置里关闭。

## 设置中心

Windows 11 开启系统“透明效果”时，Dock 和隐藏把手会实时模糊背后的桌面内容，收起和展开时毛玻璃跟随圆角轮廓变化。关闭系统透明效果、启用高对比度或系统不支持时，自动使用半透明背景。桌面卡片保持原有材质。

打开方式任选其一：

- 双击通知区域的冰蓝桌面图标；
- 单击任一卡片，点击卡片上出现的设置按钮；
- 用 Tab 键把焦点移到卡片上，点击出现的设置按钮；
- 右键卡片，选择“在冰蓝桌面中设置…”。

设置修改后立即生效，无需保存：输入框在停顿片刻、按回车或离开输入框后生效；布局预设选好后点击“应用布局”。“通用设置”页底部的“退出冰蓝桌面”用于退出程序。

| 分组 | 页面 | 用途 |
| --- | --- | --- |
| 桌面 | 桌面方案 | 首次打开设置时的首页：顶部「我想…」提供 6 个常用任务直达入口（换个外观风格、开关 Dock 或顶栏、设置天气城市、修改快捷键、隐藏桌面图标、整理桌面文件）；选“Windows 原生 / 冰蓝混合 / 苹果式”一次设好冰蓝 Dock、顶部信息条和 Windows 任务栏；“当前状态”写出三条栏的实际状态，改动过的标“已自定义”，可一键恢复方案默认；隐藏 Windows 桌面图标及可选的“双击桌面空白处切换桌面图标”（默认关闭） |
| 桌面 | 桌面卡片 | 新建待办便签、普通便签、文件收纳盒（新盒默认名为“文件收纳盒”“文件收纳盒 2”…）；左侧列表带选中高亮、底部溢出提示与右键“重命名”，右侧详情顶部固定操作栏提供名称编辑（待办/便签/文件收纳盒，与桌面卡片双向同步）、显示/隐藏、锁定位置、恢复默认位置与从桌面移除/删除；时间卡片细线、文件收纳盒自动整理收纳、“文件收纳盒自动刷新”与“允许从文件收纳盒删除原文件”收在“更多选项”，单卡配色与尺寸收在“独立外观” |
| 桌面 | 外观样式 | 所有外观设置的集中入口：首屏展示试选外观、全局材质（含纯透明（无底板））、配色、玻璃浓度、文字颜色，以及“各部分外观”（固定四行：桌面卡片、冰蓝总览卡、冰蓝 Dock、顶部信息条，每行直接看状态并可就地展开自定义或一键恢复跟随）；纯透明（无底板）推荐效果、内部底色、文字阴影、卡片间自动留白、网格对齐与标题栏按钮悬停收在“更多选项”，布局预设、主题包与从 Rainmeter 导入收在“布局预设与主题” |
| 栏 | 冰蓝 Dock | 屏幕底部的应用栏：首屏提供开关、显示器、显示方式、图标大小、悬停放大、固定应用及单行外观摘要（点击“去调整 ›”跳到外观样式页），功能入口与行为高级项收在“尺寸与高级”；偏离桌面方案时右上角提供一键恢复方案默认 |
| 栏 | 顶部信息条 | 屏幕最上方的状态栏：首屏提供开关、显示器、显示方式、模块勾选、Wi-Fi 名称开关及单行外观摘要（点击“去调整 ›”跳到外观样式页），模块左右顺序调整收在“模块顺序”，信息条高度收在“高度”；偏离桌面方案时右上角提供一键恢复方案默认 |
| 栏 | Windows 任务栏 | 系统任务栏的外观和隐藏方式：支持系统默认、透明、模糊与自动隐藏（自动隐藏时提供鼠标触边唤出与新消息防弹出开关）；偏离桌面方案时右上角提供一键恢复方案默认 |
| 工具 | 冰蓝总览卡 | 快速找应用、翻常用文件夹的全局面板：开启或关闭总览卡、录制呼出快捷键、选择背景方式（直接浮在当前窗口上 / 用桌面壁纸作底 / 先切回桌面）、最近使用文件、Everything 搜索开关及单行外观摘要（点击“去调整 ›”跳到外观样式页）；常用星标来源收在“更多选项” |
| 工具 | 通用设置 | 首屏展示登录启动、检查更新、最常用 3 条快捷键（冰蓝总览卡、常用文件夹、临时浮起文件收纳盒）与退出；其余快捷键、备份与恢复、隐私与数据目录、项目仓库与卸载收在“更多选项” |

设置窗口会记住上次打开的页面，重新打开时回到同一页。窗口顶部的搜索框（Ctrl+F）可按名称查找设置，例如“透明”“圆角”“热键”“备份”，同时也保留旧称同义词（如搜“桌面组件”“顶栏与底栏”“清爽桌面”“分组盒”“速览”“无底板”“吸附间距”均可命中）；用 ↑↓ 选择、Enter 打开，会自动切页、展开对应“更多选项”或折叠区并高亮定位到该项。

## 常用操作

- 点击 Dock 的冰蓝总览卡图标、顶部信息条居中的「搜索应用、文件…」入口，在冰蓝托盘菜单选「打开冰蓝总览卡」，或按全局热键（默认 `Ctrl+Alt+F`），均可打开或收起冰蓝总览卡（快速找应用、翻常用文件夹的全局面板）并直接聚焦搜索框。可在「设置 → 冰蓝总览卡」开启或关闭（关闭后同时隐藏顶栏入口并注销热键）。面板顶部平时并列「应用」「文件」「我的分组」三个主入口并记住上次停留的位置。
- **应用页**：顶部显示可用的 Dock 固定应用，下方支持在 8 个通用大类（办公学习、AI 应用、聊天上网、影音娱乐、游戏休闲、设计创作、开发工具、系统工具）与「A–Z」名称排列之间切换；不足 3 项的自动类别会折叠归入「其他应用」，安装/卸载/诊断/帮助文档收在「辅助入口」。右键选「更改类别」可手动指定分类（独立显示），选「恢复自动分类」改回本机规则。
- **文件页**：展示常用位置（桌面、下载、文档、图片）与冰蓝文件收纳盒快捷卡片、最近使用文件（只读读取 Windows 最近记录，可在总览卡右上角或「设置 → 冰蓝总览卡」一键关闭）以及按文件夹、文档、图片、影音、压缩包分类的文件视图。单击位置卡片或文件夹可在面板内只读展开子项，并可切换图标/列表视图或点击「打开目录」在资源管理器中查看，不移动原文件。
- 输入关键词后会跨类型和分组搜索，顶部左侧出现「全部」并可直接点击「全部／应用／文件／我的分组」或按 `Ctrl+Tab` 切换结果范围而不清空关键词，底栏可切换“仅搜当前范围”与来源筛选；清空搜索后自动隐藏「全部」并回到之前的浏览标签、分类与滚动位置。浏览模式默认不选中首项，在列表或搜索框可用方向键与 `Home`/`End` 选择（仅选中时按 Enter 打开，切换焦点至其他按钮时不会被方向键误抢）、Ctrl+1／2／3 切换主入口、Alt+Left 返回上级文件夹、Esc 收起。
- 在「我的分组」中点「新建分组」，并在选中分组后的面板顶部或左侧分组右键菜单中随时就地重命名或删除分组（仅移除分组，不删除原文件或应用）。同一组可以同时包含应用、文件和文件夹，一个入口也可加入多个组，并支持图标/列表视图切换。右键项目可加入分组、移出当前分组、固定到 Dock 或打开所在位置。
- 点击面板右上角的材质按钮可快切磨砂与清透。在「外观样式 → 各部分外观」展开冰蓝总览卡、冰蓝 Dock 或顶部信息条，即可单独设置自定义底色、玻璃浓度、磨砂玻璃与圆角，或一键点击「恢复跟随」回到全局配色。
- **发送到文件收纳盒**：右键 Dock 上有本地路径的固定项或冰蓝总览卡项目，选择「发送到文件收纳盒」并指定目标。重复发送保留一条映射，发送操作只添加引用。
- **调整任务栏位置**：进入「Windows 任务栏」，点击「打开 Windows 任务栏设置」。支持换边的 Windows 版本可在「任务栏行为」内选择位置，冰蓝随当前工作区调整。

顶栏右侧提供“托盘”按钮，可打开 Windows 隐藏图标面板，再点一次收起；在“顶部信息条”的模块设置中可关闭。面板仍由 Windows 管理，关闭面板后任务栏按原设置收回。面板的弹出位置由 Windows 决定，多显示器时出现在主显示器右下角。前台是管理员程序（如任务管理器）时，Windows 不允许普通程序向它发送快捷键，冰蓝会提示先切换到其他窗口。Windows 10 隐藏该按钮；入口不可用时可将鼠标移到屏幕底边或角落访问原生任务栏。

- **移动卡片**：拖动卡片标题或空白处；拖动卡片边缘或四角可调整大小。靠近其他卡片时会自动对齐并保持“卡片间自动留白”距离，按住 Alt 拖动可暂时关闭对齐。在“桌面卡片”页勾选“锁定卡片位置”后不会被误拖。
- **单张卡片外观、字体与时钟版式**：所有桌面卡片默认跟随“外观样式”页的全局统一配色。在“桌面卡片”页选中任意卡片后，可直接通过右侧“统一外观与配色”卡片跳去统一调整时间、问候、天气等全部组件的外观；需要单独定制某张卡片时再展开下方“独立外观”调整，点击“恢复跟随”即可改回全局外观；字体列表最前面是内置字体（得意黑、Jost、Quicksand、Abril Fatface 衬线），时间卡片选“Jost 极细”可得到细长的大号时钟。选中“时间日期”时，还可在详情上方开关“使用 24 小时制”“显示日期”“显示农历”，以及切换“经典 / 极简大数字 / 日期海报 / 纵向数字”四种时钟版式；时间日期外观默认跟随“外观样式”页的全局材质与配色（需要透明裸字时切到全局无底板或在“独立外观”选择“无底板”即可），切换版式会保留你在“独立外观”里自选的字体、字号和文字颜色。
- **修改标题**：双击待办、便签或文件收纳盒的标题，或选中卡片后按 F2（Enter 确认，Esc 放弃）；也可在设置中心“桌面卡片”页选中对应卡片后在右侧顶部名称框直接修改，或右键左侧列表条目点“重命名”，两边实时同步，留空自动回落为默认名。内置信息卡名称固定。
- **待办**：可在标题栏切换“列表 / 周历”视图。列表视图直接输入，Enter 确认，Esc 放弃本次修改；勾选方框标记完成，点击右侧“×”删除该条，右键可上移、下移。右键条目选“设为行程”可把它标为行程，再选“设置时间…”填写时间（如 14:30，留空清除）；行程不打勾、不计入未完成数，同一天始终排在待办前面，有时间的按时间先后排列，选“设为待办”可改回。周历视图按周一至周日展示（带农历初一月份与每日农历标注，可在设置中心“桌面卡片”页选中待办卡片将显示周数调为 1–5 周，默认 4 周）；格子放不下的待办会在日期旁显示“+N”，格内也可用滚轮滚动查看；单击选中格子后点标题栏“+”或点击“+N”展开当日详情浮层，周历格内删除待办用右键菜单或详情浮层，可在浮层底部回车新增、双击条目文字原地修改、指针悬停 0.3 秒抬起后拖拽调序，或右键“移到 ▸ 明天/后天/大后天”（底部弹出提示条可一键撤销）；双击任意日期格可打开单日多行编辑窗，回车自动续编序号，点击“✓”或关闭窗口自动保存。点击标题栏的折叠按钮可收起成一条并只显示当前未完成数，再点一下按原高度展开。
- **截止时间与倒数日**：在待办正文或条目空白处右键选“设置截止时间…”，选择日期，可勾选“指定时间”填写小时和分钟；未完成事项会持续显示在今日列表，完成后停止倒计时，“清除”移除截止时间。考试、纪念日等事件可选“设为倒数日”，确认目标日期后转换，不显示完成勾选框；右键“设置目标时间…”可修改。只选日期时按天计算，指定时间时显示天、小时和分钟；到点显示“已到期”，之后显示已过时间。时间使用本机时区，无提醒通知。取消或按 Esc 保留原状态。正文右键菜单中的“编辑文本”提供剪切、复制、粘贴和全选。
- **便签**：直接输入文字；单击便签后点击标题栏的“Aa”，可设置正文字体、字号、颜色、粗斜体和对齐。
- **隐藏标题栏按钮**：觉得待办和文件收纳盒标题栏上的 +、排序、收起等按钮影响美观，可在设置“外观样式”页的“更多选项”中打开“标题栏按钮仅在鼠标移上时显示”，平时只显示标题，鼠标移到卡片上时按钮才出现。
- **固定在桌面**：时间、待办、便签、文件收纳盒等卡片始终待在其他程序窗口下面，点击或拖动时也不会浮到浏览器等窗口上面；被窗口挡住时，按 Win+D 显示桌面即可完整查看。
- **文件收纳盒**：把常用文件、文件夹或快捷方式拖进文件收纳盒，只记路径不搬原文件。点击标题栏的折叠按钮可收起成一条并在标题右侧显示当前项目数，再点一下按原高度展开；也可在设置中心“桌面卡片”页选中该文件收纳盒打开“鼠标离开 5 秒后自动收起”（默认关闭），开启后展开时鼠标移开 5 秒自动折叠成标题条，单击标题条即可重新展开（在盒内悬停或打开菜单/对话框时不会误收）。按全局快捷键（默认 `Ctrl+Alt+Space`）可“临时浮起文件收纳盒”到当前窗口上层拿文件或拖文件，松开或按 Esc 退回。双击打开；右键可修改显示名称（不重命名原文件）或转移到其他文件收纳盒；在设置“桌面卡片”页选中文件收纳盒后展开“更多选项”开启“文件收纳盒自动刷新”（默认关闭，对所有文件收纳盒生效）后，桌面上新出现的文件自动收纳进已有的文件收纳盒（下载中的临时文件等改名完成后才入盒），原文件被删除后对应项自动从盒中清除；因 U 盘或网络盘未连接而暂时找不到的项会保留并显示“已失效”，右键可重新定位。“自动整理”会把桌面项目放进各文件收纳盒，并顺带清除残留的“已失效”项；在设置中心“桌面卡片”页选中文件收纳盒，展开“更多选项”可勾选它收纳的类型（如文档、图片、压缩包）或填写其他扩展名，自定义自己的收纳盒。
- **删除原文件**：文件收纳盒默认只移除映射、不动原文件。需要直接删除时，在设置“桌面卡片”页选中文件收纳盒，展开“更多选项”打开“允许从文件收纳盒删除原文件”，之后右键选择“删除到回收站…”或选中项目按 Delete 键，确认后原文件进入回收站，可以还原。U 盘、网络位置、磁盘根目录和系统文件夹不能这样删除。
- **隐藏 Windows 桌面图标**：在“桌面方案”页打开“隐藏 Windows 桌面图标”（旧称“清爽桌面”），只显示冰蓝卡片和文件收纳盒，桌面更干净。开启时显示快捷入口，可访问此电脑、回收站、下载和桌面。之后可在“桌面卡片”页隐藏快捷入口，重启后保留该设置。关闭开关或退出冰蓝后，Windows 桌面图标自动恢复。若桌面图标仍处于隐藏状态，可点开关旁的“恢复显示”。同位置下方还提供默认关闭的“双击桌面空白处切换桌面图标”开关：开启后在桌面空白区域左键双击即可隐藏或恢复桌面图标，双击桌面图标或其他应用窗口不会误触发，本项为本机设置不随主题包导出。
- **Dock 应用**：Dock 左侧依次显示 Windows 开始菜单、冰蓝总览卡和显示桌面。可在「冰蓝 Dock → 尺寸与高级」分别显示或隐藏。单击打开 Windows 原生开始菜单，右键打开原生系统快捷菜单（Win+X）；系统菜单打开时 Dock 暂时收起。按住 Shift 或 Ctrl 点击开始入口同样会打开开始菜单；前台是管理员程序时，右键菜单会提示先切换到其他窗口。在 Dock 分区点击“导入任务栏应用”可导入任务栏上固定的应用。把程序、文件、文件夹、快捷方式或文件收纳盒里的软件图标拖到 Dock 空白区、固定文件/文件夹或角落把手上可固定（文件和文件夹只记录路径，点击后用资源管理器或默认程序打开）；把图片、文档等普通文件（或指向文件的快捷方式）直接拖到 Dock 上的应用图标上，则会直接用该应用打开这些文件，在运行中的应用图标上悬停约 0.5 秒还可自动抬起或还原其窗口；正在运行的应用拖到 Dock 左侧的固定段也会固定。右键 Dock 空白处或在设置中心 Dock 分区点“添加应用…”，会列出开始菜单里的应用，搜索后勾选即可。右键固定的应用可更换图标或取消固定。图标大小在设置中心 Dock 分区调整；外观默认跟随全局，可在「外观样式 → 各部分外观 → 冰蓝 Dock」（或从冰蓝 Dock 页点“外观 → 去调整 ›”）展开后选“自定义”，调整配色、任意颜色与不透明度。“自动缩小图标”默认开启：应用较多放不下时自动缩小图标（最小 28，Dock 高度不变）；关闭后或缩到最小仍放不下时，行尾出现“查看全部应用”按钮（点击列出全部应用），也可以在 Dock 上用鼠标滚轮横向滚动，不会再有应用被裁掉看不见。应用来消息时，Dock 图标右上角会出现提醒标记：把未读数写进标题的应用（如 QQ）显示红色数字，微信等不发布计数的显示橙色圆点；不想让隐藏的任务栏因此弹出，在“Windows 任务栏”分区（选自动隐藏时显示）打开“有新消息时不弹出任务栏”。Dock 设为智能隐藏后，可在 Dock 分区的“唤出方式”中选择从屏幕底边和把手唤出、只用把手，或只用屏幕底边（不显示把手）；原生任务栏一直显示时，鼠标停在任务栏上不会唤出 Dock：默认用把手唤出；选“只用屏幕底边”则不显示把手，把鼠标推到屏幕最底边即可唤出。智能隐藏默认只在窗口挡住 Dock 时收起；打开“始终自动隐藏”后 Dock 平时一直收起，只在鼠标碰到边缘或把手时出现。应用闪烁提醒（如聊天软件来消息）时，已收起的 Dock 默认不会弹出，标记显示在图标上；需要时可打开“有新消息时临时弹出 Dock”。应用闪烁提醒时，它在 Dock 上的图标会弹跳几下（设置“有新消息时图标弹跳”，默认开；遵循“动画”档位与系统动画开关，同一应用 8 秒内至多一次）；Dock 已收起时，把手会闪动几下。
- **顶部系统状态**：点击电量、网络或音量会打开 Windows 快速设置，再点一次收起；快速设置确实无法打开时才分别打开对应的 Windows 设置。点击输入法会弹出输入法切换列表，可直接点选已启用的输入法或键盘布局，底部也可直达 Windows 键盘与语言设置。顶部信息条不调节音量、亮度或网络设置。
- **任务栏鼠标触边唤出**：任务栏设成自动隐藏后，鼠标移到底边可唤出原生任务栏。在设置中心“Windows 任务栏”页（选自动隐藏后显示）的“鼠标触边唤出”可选“底部任意位置”“仅底部两角（默认）”或“禁止鼠标触边唤出”。开启限制后，底边最下 2 行像素会被一条透明细条占住，该处无法点击其他程序；在全屏游戏、视频等窗口中自动暂停。该选项只限制鼠标唤出，按 Win 键或打开开始菜单等系统面板时，Windows 仍可能显示任务栏。
- **搜索文件与应用**：搜索能力统一由冰蓝总览卡承载。开启顶部信息条与“搜索”模块后，会在顶栏正中显示「搜索应用、文件…」入口按钮，点击或按下全局热键（默认 `Ctrl+Alt+F`，可在设置中心“冰蓝总览卡”页自定义录制）即可打开/收起总览卡并聚焦搜索框。总览卡默认搜索桌面、开始菜单应用与 Windows 已索引的文件名，无需安装 Everything；系统索引范围取决于 Windows 设置，未索引目录不会被额外扫描，系统索引不可用时仍可搜索桌面与应用。若本机已运行完整版 Everything，可在「设置 → 冰蓝总览卡」勾选「使用 Everything 搜索文件」；未运行或不可用时自动回退 Windows 索引。搜索时支持输入法本地文字输入与 Shift 切换英文，单击结果或按 Enter 打开，Esc 收起。
- **隐藏全部卡片**：右键通知区域图标，选择“隐藏桌面组件”；再次选择可重新显示。

## 主题包

在“外观样式”页的“布局预设与主题”中导出主题，可分享给别人。主题包包含卡片外观、布局、整体风格、Dock 应用和自定义图标，不包含称呼、城市、待办、便签、文件位置、壁纸、字体、Dock 开始菜单入口和显示器选择等本机设置。导入前可查看预览，导入时会先备份当前设置。

## 恢复与卸载

- 任务栏透明只在已验证的 Windows 版本上启用，不支持时会在设置页说明。TranslucentTB 等任务栏工具运行时，冰蓝桌面会让出任务栏。
- 退出冰蓝桌面后，任务栏和桌面图标恢复原样。透明背景在冰蓝异常退出后也会自动恢复；自动隐藏和桌面图标在下次启动时恢复。
- 若任务栏或桌面图标没有恢复：任务栏在 Windows 设置 > 个性化 > 任务栏中调整；桌面图标在桌面右键菜单“查看”中勾选“显示桌面图标”。
- 卸载：在设置中心“通用设置”页展开“更多选项”点“卸载…”，或在开始菜单搜索“卸载冰蓝桌面”。免安装版没有卸载程序，退出后删除文件夹即可。
- 卸载时会询问是否删除个人数据，默认保留；选择删除时数据移到回收站。
- 数据保存在 `%LOCALAPPDATA%\BingLanWidgets`。

## 联网与隐私

联网只用于天气和检查更新。冰蓝桌面每天向 GitHub 查询一次最新版本号，不发送个人数据，可在“通用设置”页关闭；发现新版本时只提示，点“下载并安装”后才下载，安装时冰蓝桌面会暂时退出，装完自动重新打开。天气位置由你手动选择，不使用 IP、GPS 或 Wi-Fi 定位。冰蓝桌面不收集使用数据，也不上传待办、文件位置、应用列表或窗口标题。
