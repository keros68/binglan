## 安装

下载 `BingLan-Setup-0.2.13.exe` 运行即可，直接覆盖安装旧版本；或下载 `BingLan-0.2.13-portable.zip` 免安装版，解压到任意文件夹后运行其中的 `BingLan.exe`。两者均按当前用户运行、自带 .NET 运行时，尚未加入代码签名，首次运行需按 Windows 提示手动放行。需要 Windows 11，或 Windows 10 版本 2004 及以上。已安装 0.2.2 及以上版本的可在设置中心“通用”页检查更新后直接安装（免安装版更新请重新下载 zip 覆盖，不要用应用内“下载并安装”，它安装的是安装版）。

## 这一版的改进

- **顶端信息条**（新功能）：屏幕顶部一条满宽信息条，时钟与日期、待办概要、天气、CPU/内存/网速、电量、音量、网络、输入法（任务栏式中/英徽标与输入法名）、应用闪烁提醒九个只读模块独立开关；点击待办弹出清单可随手勾选、点击性能打开任务管理器、点击电量/音量/网络唤起系统快速设置、点击时钟弹出月历。支持“始终显示并预留顶部空间”（高度 24–48 DIP 可调）或智能隐藏；深色菜单栏外观配任务栏同款 Fluent 状态图标，磨砂玻璃对壁纸做真实模糊（可关闭）。桌面模式选“苹果式”会自动开启信息条并收起桌面上重复的信息卡。
- **Dock**：Dock 悬空（距底高度、让出残留）时，唤出区从 Dock 底边延伸到屏幕底，指针从屏幕边移向 Dock 不再中途隐藏、图标点得到。
- **新增免安装版**：绿色 zip，解压即用，与安装版功能一致。
- 显示桌面（Win+D）判定跳过被系统挂起的后台窗口，个别机器上卡片偶发不提升的问题已修复。

顶端信息条与 Dock 唤出区由社区贡献者 [@coder-zhijiu](https://github.com/coder-zhijiu) 提交（PR #4、#5）。

## 已知限制

- 顶端信息条已在 Windows 11 26200 双显示器（贡献者真机）与 2560×1440·125% 缩放（本机）验证；混合 DPI 多显示器、Explorer 重启后的顶边预留重放尚未穷尽验证
- 磨砂玻璃依赖系统透明效果；Windows 10 上磨砂表现可能与 Windows 11 有差异，可随时关闭
- 待办条目文字样式未随 Rainmeter 主题调整
- 境外城市搜索仍依赖 OpenStreetMap 在线服务，无可用网络或代理时会超时
